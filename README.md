# 조선퇴마록 (朝鮮退魔錄)

> 요괴가 들끓는 조선 팔도를 여섯 퇴마사가 걷는다.
> 《뱀파이어 서바이버즈》식 자동 전투 위에 조선의 직업·신령·요괴를 얹은 **도트 그래픽 로그라이크 웹게임**입니다.

## 기본 조작

- **조작:** PC는 `WASD`·방향키로 이동, 휴대폰은 화면을 누른 채 끌어 이동합니다. 공격은 모두 자동입니다. 오른쪽 아래 버튼은 왼쪽부터 **신내림·소리·상태·정지**입니다.
- **캐릭터 상태창:** `C`(또는 `Tab`) 키, 휴대폰은 오른쪽 아래 **상태** 버튼. 지금 쓰는 무기·직업 기술·보패·축복·정표와 능력치, 무기마다 이번 출정에서 준 피해·비중·분당 피해를 봅니다. 열어 둔 동안 게임이 멈춥니다.
- **레벨업 단축키:** 숫자 `1~4` 고르기, `R` 산통 흔들기, `X` 물리기, `B` 봉인, `Space` 신내림, `ESC`·`P` 일시정지.
- **언어:** 한국어·简体中文. 시작 화면 맨 위 「한국어｜中文」 단추나 설정의 「언어」에서 바꿉니다. 처음에는 기기 언어를 따릅니다(중국어면 간체).
- **분위기 효과:** 설정에서 켬·약하게·끔을 고릅니다. 밤의 어둠·불빛·잔해·풀·날씨·바닥 무늬는 보기만 하는 효과라 게임 규칙은 바뀌지 않고, 요괴 탄·보스 경고·피해 숫자는 늘 어둠 위에 또렷하게 그립니다. 절약 모드에서는 어둠 한 겹만 남깁니다.
- **저장:** 진행(엽전·과업·해금·설정)은 이 브라우저 저장소(localStorage)에만 남습니다. **휴대폰을 바꿀 때**는 설정 → 「저장」의 **「저장 내보내기」**로 `조선퇴마록-저장-날짜.txt` 파일을 받아 새 기기로 옮긴 뒤(메일·메신저·클라우드 등), 새 기기 설정에서 **「저장 가져오기」**로 그 파일을 고릅니다. 가져오기 전 진행은 「불러오기 전으로」로 되돌릴 수 있습니다. 아이폰은 **사파리와 홈 화면 앱의 저장이 따로**라, 홈 화면에 추가한 뒤 처음 열 때도 같은 방법으로 옮깁니다. 파일을 쓸 수 없으면 「저장 코드로 옮기기」에서 글자 한 줄을 복사·붙여넣어도 됩니다. 처음부터 다시 하려면 설정의 「처음부터 다시」를 누릅니다.

## 1. 세계관

조선 땅에 밤이 길어졌다. 저잣거리에는 도깨비불이 떠다니고, 고갯길에는 사람을 홀리는 장산범이 울고, 동해 바닷가 하늘에는 사람 얼굴을 한 인면조가 맴돈다. 관아는 손을 놓았고, 무당의 굿도 더는 닿지 않는다.

그래서 저마다 다른 재주를 지닌 여섯이 길을 나선다. **붓으로 기를 싣는 선비**, **침과 약으로 살리고 독으로 베는 의원**, **신을 몸에 받는 무당**, **활과 칼과 총통을 쥔 장수**, **노래와 춤으로 칼을 휘두르는 기생**, **주판알과 엽전으로 셈하듯 요괴를 치는 상인**. 이들은 한양 저잣거리에서 출발해 범 나오는 고개와 백두산 골짜기, 동해 바닷가와 저승길을 지나, 마침내 요괴가 똬리를 튼 경복궁 근정전 앞뜰까지 열 개의 막을 차례로 평정해야 한다.

혼자 걷는 길은 아니다.

- **신령의 축복:** 성황당에서 빌면 산신·성황신·조왕신·사신(청룡·백호·주작·현무) 같은 열두 신령이 축복을 내린다. 짝이 맞는 두 신령은 함께 **쌍신 축복**을 내리고, 쌓인 믿음은 **신내림**이 되어 한 번에 터진다.
- **하늘 신령의 강림:** 단군신화에서 환웅을 따라 내려온 **풍백·우사·운사**가 막마다 한 번 구름을 타고 내려와 30초 동안 가호를 준다.
- **도사 전우치:** 체력이 위태로우면 분신술로 나타나 요괴를 쓸고, 금강불괴의 도술로 퇴마사를 지킨다.
- **산짐승 동무:** 첫 전직을 마치면 **범·반달곰·해동청** 가운데 하나가 동무가 되어 함께 싸운다.

길 위에 나오는 요괴 쉰여덟 종의 이름은 고성배 작가의 『한국 요괴 도감』(위즈덤하우스, 2019)에 실린 요괴에서 따왔습니다. 게임 속 행동과 기술은 놀이에 맞게 새로 지어냈습니다.

## 2. 게임의 흐름

| 단계 | 내용 |
|---|---|
| 출정 준비 | 퇴마사·**출정 방식(출정/퇴마 원정)**·난이도·**정표**·점괘 패(세 장까지)·액운 단계를 고른다. |
| 한 막 (120초) | 요괴가 점점 몰려온다. 구슬을 모아 레벨업하고 무기·보패를 고른다. **막 의뢰**를 풀고, **연격**을 잇고, **도깨비 샛길**에 들지 말지 정한다. |
| 60초 | **중간 보스** 등장. 어려움 난이도에서는 엘리트와 함께 나온다. 엘리트는 중간 보스를 쓰러뜨리기 전에는 막의 기존 엘리트, 쓰러뜨린 뒤에는 **막별 새 엘리트**(v19.4~v19.5: 1~10막)가 나온다. 설화 출정은 기존 엘리트. |
| 120초 이후 | 중간 보스를 쓰러뜨렸다면 **막 보스** 등장. 쓰러뜨리지 못했다면 막 보스는 나오지 않는다. |
| 막 평정 | 도깨비 보물(샛길에 들었다면) → 갈림길 보상(대장간이면 **담금질**) → 보물 상자 → **주막**에서 엽전으로 정비 → **갈림길**에서 다음 길 선택 |
| 제10막 평정 | 출정 성공. 여기서 마치거나 **끝없는 밤**으로 이어 간다. 남은 엽전은 수련 도장에서 쓰는 엽전이 된다. |
| 출정이 끝나면 | 이기든 쓰러지든 **퇴마사 본부**로 돌아온다. 식구와 이야기하고 막걸리를 건네 **정표**를 받는다. 이번 출정은 날짜와 함께 **기록관**에 남는다. |

- **레벨업:** 세 장(운이 좋으면 네 장) 가운데 하나를 고른다. **산통 흔들기**(새로 뽑기), **물리기**(건너뛰고 엽전 5닢), **봉인**(이번 출정에서 다시 안 나오게)을 쓸 수 있다.
- **진화 짝 안내:** 레벨업 카드에 진화 조합이 나온다. 보패 카드에는 그 보패와 짝인 무기(가진 무기는 금색 「보유 LV」, 안 가진 무기는 흐리게)와 진화 이름이, 무기 카드에는 짝 보패를 가졌는지가 보인다. 가진 무기와 짝이 맞는 카드는 **금색 테두리와 「진화 짝」 표식**으로 강조되고, 진화 준비가 끝나면 「보물상자를 열면 진화」라고 알려 준다.
- **칸과 2단계 성장(v20.6):** 무기는 네 칸, 보패도 네 칸이다(직업 기술은 칸 밖). 진화·합공 무기는 진화 Lv 1~5, 직업 기술은 Lv 5 뒤 숙련 1~3으로 더 자라 성장이 9~10막까지 이어진다. 한 단계 오를 때마다 피해 +10%와 함께 몸도 단련된다(최대 체력 +6, 초당 회복 +0.075).
- **전직:** Lv 10·20·30·40·50마다 전직한다. 1차 전직에서 두 갈래 길 중 하나를 고르고, 전직마다 새 기술·새 외형·직함 보너스를 받고, 2차부터는 함께 받을 수련 카드 셋 가운데 하나를 고른다. 전직 창은 쌓인 레벨업 카드보다 먼저 열린다.
- **설정:** 효과음, 화면 흔들림, 피해 숫자, 화면 번쩍임, **내 기술 효과 진하기(진하게/보통 70%/흐리게 40%)**, 도트 크기(그림과 함께 보이는 넓이도 바뀜), **캐릭터·요괴 크기(기본/2배: 보이는 넓이와 맞는 범위는 그대로 두고 플레이어·펫·전우치·요괴 그림만 2배, 보스는 1.5배까지. 그리기 판을 2배 정밀로 그려 도트가 깔끔하고, 화면이 느려지면 저절로 기본으로 돌아감)**, 터치 조이스틱, **성능 모드(자동/고화질/절약)**, 초당 프레임 표시, **오류 기록**(게임이 멈추거나 오류가 나면 이 기기에만 적어 두고 복사·지우기, 바깥으로 보내지 않음).

## 13. 기술 구조

- **파일 하나:** HTML·CSS·자바스크립트가 `index.html` 한 파일에 모두 들어 있습니다. 외부 라이브러리는 쓰지 않고, 글꼴만 Google Fonts에서 불러옵니다(오프라인이면 기본 글꼴로 대체).
- **그리기:** 낮은 해상도의 버퍼 캔버스에 도트를 그린 뒤 정수 배율로 확대해 화면에 옮깁니다(이미지 보간 끔). 모든 캐릭터·요괴·아이콘은 코드 안의 픽셀 문자열로 그려 이미지 파일이 없습니다.
- **데이터 중심 설계:** 무기(`WD`), 보패(`PD`), 요괴(`EN`), 막(`STAGES`), 보스 기술(`BSK`), 신령(`BLESS`), 쌍신(`DUO`), 신내림(`CALL`), 펫(`PETS`), 과업(`TASKS`), 담금질(`TEMPER`), 본부 식구(`NPCS`), 설화(`TALES`)·설화 막 규칙(`TALE_RULES`)·본편 결말(`ENDING`) 같은 표를 바꾸면 게임 내용이 바뀝니다.
- **충돌 처리:** 공간 격자로 가까운 요괴만 검사합니다.
- **난수(v20.1~):** 판의 일(요괴 등장·드롭·레벨업 선택지·치명타·피해 흔들림)은 `rand()`·`rnd()`로, 판마다 씨앗(`G.seed`)에서 만든 난수를 씁니다. 그리기·소리·잔상·피해 숫자처럼 보이기만 하는 것은 `vrand()`·`vrnd()`를 씁니다(그리기 횟수나 절약 모드의 잔상 상한에 따라 판이 달라지지 않게). 오류 기록의 씨앗을 주소 `?seed=숫자`에 붙이면 같은 판으로 시작합니다. 게임은 화면 빠르기와 상관없이 늘 1/60초씩 진행해(v20.3), **같은 씨앗·같은 조작**이면 어느 기기에서나 같은 판입니다(사람의 조작은 기록하지 않으므로 사람이 한 판을 그대로 다시 볼 수는 없음 — 자동 플레이·시험용).
- **저장:** 브라우저 `localStorage`의 `joseon-toema-v1` 키에 엽전·과업·해금·설정·본부(정과 정표)·기록관을 저장합니다. 불러올 때마다 제대로 읽힌 저장을 `joseon-toema-v1-bak`에 한 벌 더 두고, 읽을 수 없는 저장은 `joseon-toema-v1-broken`에 옮긴 뒤 백업으로 시작합니다(v19.8). 저장 코드는 `JTM1:` + base64(UTF-8 JSON).
- **홈 화면 앱(PWA):** `manifest.webmanifest`(앱 이름·아이콘·전체 화면 설정)와 `sw.js`(오프라인 저장)가 함께 배포됩니다. 게임 파일은 늘 네트워크를 먼저 확인해 새 판을 받고, 인터넷이 없을 때만 저장본으로 엽니다. 아이콘은 `docs/app/`에 있습니다.
- **에셋 도감(v20.8~):** `python3 tools/assets.py`가 실제 브라우저(Playwright)로 빌드된 `index.html`을 열어 **게임의 그리기 함수 그대로** 그림을 뽑습니다. 결과는 도감 페이지(`docs/assets/index.html` · 목록 `assets.json` · 종류별 대표 시트 `sheets/`)와 README·안내서 그림(`docs/img/`, 지금 파일 이름 그대로)입니다. 그릴 목록과 그리는 법은 `tools/assets_list.js`에 있고, 게임 코드는 건드리지 않습니다. 도트를 고친 뒤 이 명령 한 번이면 도감과 README 그림이 함께 새로 그려집니다(같은 입력이면 같은 파일). `--check`는 쓰지 않고 `docs/img`가 게임과 어긋난 곳만 보고합니다. 도장 글자 그림은 글자·바탕·글자 색(`assets.json`에 기록)이 바뀔 때만 다시 그립니다(글꼴·그림자 차이로 파일이 바뀌지 않게). 장면 캡처(배너·본부 등)는 도구가 만들지 않습니다.
- **배포:** `gh-pages` 브랜치의 `index.html`이 GitHub Pages로 서비스됩니다. 게임을 고치면 `main`과 함께 `gh-pages` 브랜치에도 푸시해야 플레이 링크에 반영됩니다.
