# 배경음 v21.0 작업 계획

**목표**: 코드로 작곡한 국악풍 배경음 21곡(막 10 · 보스 판 10 · 본부 1)을 미리 mp3로 만들어, 게임이 상황에 맞는 곡을 받아 반복 재생한다.
**구조**: `tools/bgm/compose.js` + `tools/bgm.py`가 브라우저로 곡을 만들어 `audio/bgm/`에 쓴다. 게임은 `bgmWanted()`(상태 → 곡·크기)를 1초에 네 번 보고 `bgmTick`이 받기·바꾸기(2초 겹침)를 한다. `sw.js`는 음원을 판 번호와 따로 저장.
**설계서**: `docs/specs/2026-11-15-배경음-v21.0.md`

## 지킬 것
- 시험 먼저(실패 확인) · `src/` 고친 뒤 `python3 build.py` · 판 번호는 `GAME_VER` 한 곳
- 브라우저 시험·곡 만들기는 하나씩(기계가 다시 시작됨) · 커밋·푸시는 허락 뒤 · 올리기 전 GitHub 최신 확인
- 새 글은 `_t` + 간체 · 설정 기본값은 옛 저장에도 들어가게

## 살필 것 (시험이 놓치기 쉬운 순서)
1. 아이폰에서 첫 터치 전에 재생을 시도해 소리가 영영 안 남 → 작업 3 「터치 전엔 받기만, 터치 뒤 재생」
2. 보스 판 ↔ 막 곡이 매 프레임 오가며 깜빡임(보스가 잠깐 사라지는 순간) → 작업 2 「곡이 바뀐 뒤 1초는 다시 바꾸지 않음」
3. 오프라인에서 음원 대신 게임 화면이 와서 풀기 오류가 쌓임 → 작업 4 `sw.js` 404 · 작업 3 실패는 한 번만 기록
4. 막을 빨리 넘길 때 받는 중인 곡이 뒤늦게 틀어짐 → 작업 3 「받은 뒤 그때 원하는 곡이 아니면 틀지 않음」
5. 메모리: 곡을 계속 쌓음 → 작업 3 「3곡 넘으면 오래된 것 버림」
