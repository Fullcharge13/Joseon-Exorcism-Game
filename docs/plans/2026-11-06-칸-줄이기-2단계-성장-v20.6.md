# 칸 줄이기 · 2단계 성장 v20.6 작업 계획

**목표**: 무기·보패를 4칸으로 줄이고, 진화·합공 무기는 진화 Lv 1~5, 직업 기술은 숙련 1~3으로 오래 키워 성장이 9~10막까지 이어지게 한다.
**구조**: 무기 하나에 `ev2`(진화 레벨 0~5)와 `mas`(숙련 0~3)를 두고, 힘은 한계 돌파와 같은 자리(`runW`, `src/js/03_systems.js`)에서 실행 직전에 붙였다 되돌린다. 레벨업 선택지(`genOptions`, `src/js/10_ui.js`)에 「진화 Lv」·「숙련」 카드를 더하고 칸 수와 한계 돌파 조건을 바꾼다.
**도구**: 캔버스 2D 한 장 HTML · Node 하네스 단위 시험 · Playwright · 자동 플레이 봇(`tests/sim/tale_bot.js`)
**설계서**: `docs/specs/2026-11-06-칸-줄이기-2단계-성장-v20.6.md`

## 지킬 것
- 판 번호는 `GAME_VER` 한 곳 · `src/` 고친 뒤 `python3 build.py` · 커밋은 사용자 허락 뒤
- 시험 먼저(고치기 전 실패 확인) · 시뮬레이션은 2~4개씩(기계가 다시 시작됨) · 올리기 전 GitHub 최신 확인(다른 세션)
- 새 글은 `_t`로 감싸고 간체를 함께(간체에 한글 없음), `tools/i18n_keys.py` 다시 뽑기

## 살필 것 (시험이 놓치기 쉬운 순서)
1. 진화 짝 보패를 칸에 못 넣어 진화가 막힐 때 레벨업 창이 빈 선택지만 나옴 → 작업 2 「모두 찼을 때 회복·엽전」
2. 합공으로 칸이 비었는데 새 무기 카드가 안 나옴(칸 셈에 합공 무기를 잘못 셈) → 작업 2 「합공 뒤 새 무기 카드」
3. 진화 Lv·숙련의 힘이 `runW`의 빠른 길(보정 없을 때 바로 실행)에서 빠짐 → 작업 1 「보정이 진화 Lv뿐인 무기도 힘이 붙음」
4. 설화 출정의 정해진 시작 무기가 4개를 넘음 → 작업 2 「설화 출정 시작 무기 ≤ 4」
5. 인장·담금질 선택지가 붙일 곳이 줄어 효과 없는 선택지가 나옴 → 작업 4 전수 검사
