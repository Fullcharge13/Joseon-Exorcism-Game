# 분위기 층 v18.2 · 작업 계획 (바탕: 밤·색감·빛·잔해·설정)

- **목표**: 막이 갈수록 깊어지는 밤과 빛나는 물건·잔해로 화면에 분위기를 입힌다. 규칙·밸런스는 그대로.
- **구조**: 새 파일 `src/js/08c_vfx.js`(막별 표 `STAGE_VFX` + 그리기). 엔진은 부르는 자리 세 곳(바닥 뒤 `vfxGround`, 피해 숫자·요괴 탄 직전 `vfxLight`, `kill` 안 `vfxDebris`)만 고친다. 무거운 그림은 미리 굽는다.
- **기술**: 캔버스 2D(지금과 같음), Node 가짜 화면 시험, Playwright
- **설계**: `docs/specs/2026-11-01-분위기-층.md`
- **지킬 것**: 게임 규칙·맞는 범위 그대로 · 요괴 탄·경고 장판은 스스로 빛남 · 피해 숫자·요괴 탄·체력 막대·가장자리 화살표는 빛 층 위 · 퇴마사 둘레 반지름 40은 늘 밝음 · 빛 ≤ 45, 잔해 ≤ 260(절약 15·60) · `meta.set.vfx` 기본 `'on'` · 화면 버전 `v18.2`, `sw.js` `joseon-v18.2` · 새 문구는 간체 사전에도
- **커밋**: 마무리 보고 뒤 허락

## 검토 때 특히 볼 곳

1. 어둠에 요괴 탄·경고 장판·피해 숫자가 묻힘 → 작업 4 `vfx_read`(끈 때 밝기의 85% 이상)
2. 휴대폰에서 느려짐 → 작업 4 `vfx_perf`(≤ 33ms, 끔보다 +8ms 이하, 절약 +2ms 이하)
3. 요괴가 많이 죽는 후반에 잔해가 끝없이 쌓임 → 작업 1 `vfx_cap`
4. 옛 저장·엉뚱한 설정값에서 오류 → 작업 1 `vfx_table`
5. 설정 줄이 늘어 한국어 회귀 시험이 깨지거나, 새 문구가 간체에 없음 → 작업 3 `i18n_cover`, `i18n_ko_same`
