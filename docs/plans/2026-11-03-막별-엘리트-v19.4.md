# 막별 엘리트 v19.4 · 작업 계획 (틀 + 1~5막)

**목표**: 중간 보스 뒤에 나오는 막별 새 엘리트의 틀을 만들고, 1~5막 다섯 종(객귀·죽통 나그네·범이 된 남편·곰나루 암곰·길달)을 넣는다.

**구조**: 새 엘리트는 적 표 `EN`에 `elite2:1`·`frames`·`eai`(행동 이름)를 가진 항목으로 넣고, 막 표 `STAGES[i].elite2`에 아이디를 둔다. 행동은 `ELITE_AI[eai](e,dt,P,d,dx,dy)` 표의 함수로 붙여 적 갱신의 기존 `if(e.elite){…ringB…}` 자리에서 부른다(엔진은 갈래만 하나 늘림). 그림은 12×16 격자 세 장을 `variants()`로 만들어 `ESPR[id]`(걷기1)·`ESPR2[id]=[걷기1,걷기2,행동]`에 두고, 그리기에서 `e.act`(행동 중)·시간으로 고른다. 새 파일 `src/js/06b_elite2.js`에 내용(표·행동·그림)만 둔다.

**기술**: 기존 그대로 — `<canvas>` 2D, `build.py`, `tests/harness.js`, Playwright.

**설계서**: `docs/specs/2026-11-03-막별-엘리트.md`

## 지킬 것 (설계서에서 그대로)

- 중간 보스를 쓰러뜨리기 전(`!G.midDone || G.mid`)에는 `STAGES[i].elite`, 뒤에는 `STAGES[i].elite2`(없으면 `elite`). 간격·체력 ×10·보물 상자·출현 알림·삼재·액운 3 그대로. 퇴마 원정 없음. 어려움의 `eliteWithMid`는 기존 엘리트
- 행동 시작 전 경고 0.6~1초. 보스는 대상 아님. 행동은 퇴마사에게만
- 시작값: 객귀 3초 −35%·물러남 2초·다시 6초 / 죽통 8초마다 둘, 동시 ≤ 4, 여인 체력 일반 ×2 / 범 7초마다, 경고 1초, 고리 반지름 40, 피해 접촉 ×1.5 / 암곰 새끼 둘, 새끼 하나당 이동·피해 +25% / 길달 6초마다, 거리 80~120, `pushOut`, 탄 8
- 그림 12×16, 세 장(걷기 0.25초 번갈아 + 행동), 다듬기·어두운 테두리 적용. 보조물(대통 여인 `juknyeo`·새끼 곰 `gomsaekki`) 8×12 한 장, `helper:1`(도감·퇴치 과업·엘리트 상자에서 뺌)
- 도감 58 → 63(v19.4). 「도감 완성」 목표 58은 v19.5까지 그대로. 출처 이름은 도감 설명 끝, 각색은 「게임 속 각색」
- 간체: 엘리트 → 精英, 요괴 → 妖怪. 버전 `v19.4`, LOG·README, 커밋은 보고 뒤 허락

## 놓치기 쉬운 곳 (시험으로 묶음)

1. 보조물(`helper`)이 도감 수·「요괴 사냥」 과업·`G.rs.elites`·보물 상자에 끼어듦 → 작업 1 시험: 보조물은 `DOGAM_IDS`에 없음, 죽여도 상자·엘리트 수 0
2. 객귀 들러붙음이 퇴마사 무적·되살아남·끝(`G.over`) 중에도 남음 → 작업 2 시험: 무적이면 안 붙음, 판이 끝나면 이동 배율 원래대로
3. 길달 순간이동 자리가 장애물 안·막 경계 밖 → 작업 3 시험: 씨앗 30개에서 나타난 자리가 모두 `pushOut` 뒤 자리와 같고 막 안
4. 곰나루 암곰이 새끼 없이 나왔을 때(새끼 수 상한·화면에 요괴가 꽉 찼을 때 `CAP.e`) 오류 → 작업 3 시험: 적이 가득해도 오류 없음, 새끼 0이어도 성남 0
5. 행동 그림으로 바뀐 채 멈춤(행동 도중 쓰러짐·얼림 `frz`) → 작업 1 시험: 쓰러진 뒤·얼린 동안 `e.act`가 남아 그리기 오류 없음
