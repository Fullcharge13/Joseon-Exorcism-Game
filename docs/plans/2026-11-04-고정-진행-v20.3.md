# 고정 진행 v20.3 작업 계획

**목표**: 게임 진행을 늘 1/60초로 해 같은 씨앗·같은 조작이면 fps와 상관없이 같은 판.
**구조**: `frame()`에 모아 둔 시간(`acc`)을 두고 1/60초씩 `update`. 그리기·HUD는 실제 시간 그대로.
**도구**: 캔버스 2D 한 장 HTML · Node 하네스 단위 시험 · Playwright 브라우저 시험
**설계서**: `docs/specs/2026-11-04-고정-진행-v20.3.md`

## 지킬 것
- 판 번호는 `src/js/05_meta_save.js`의 `GAME_VER` 한 곳(빌드가 `sw.js`·`verTag`를 맞춤)
- `src/` 고친 뒤 `python3 build.py`, 커밋은 사용자 허락 뒤에만
- 시험 먼저: 고치기 전 실패를 눈으로 확인

## 살필 것 (시험이 놓치기 쉬운 순서)
1. 진행 밖에서 장면 길이로 게임 상태를 바꾸는 코드(144Hz에서만 드러남) → 작업 1 `frame_only_update`
2. 창이 진행 중에 열린 뒤 모아 둔 시간이 남아 창 닫힌 직후 한꺼번에 흐름 → 작업 2 `timestep` 「창 뒤 시간」
3. 화면을 떠났다 돌아올 때 모아 둔 시간이 남음 → 작업 2 `timestep` 「visibilitychange 뒤 acc 0」
4. 부동소수 쌓임으로 진행 횟수가 하나 모자라거나 남음(긴 판) → 작업 2 「60fps 600초 = 진행 36,000번」
5. 30fps 휴대폰 부담 → 작업 3 성능
