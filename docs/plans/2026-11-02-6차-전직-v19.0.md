# 6차 전직 v19.0 · 작업 계획 (뼈대 + 선비·의원·장수)

> 실행: 작업마다 시험(먼저 실패 확인) → 구현 → 검토. 체크칸(`- [ ]`)으로 진행을 적는다.

**목표**: 5차를 마친 퇴마사가 Lv 60에 6차 전직(실존 인물)하는 뼈대를 만들고, 선비·의원·장수 여섯 갈래의 인물·기술·차림을 넣는다.

**구조**: 6차 내용은 새 파일 `src/js/03b_tier6.js` 한 곳에 둔다(빌드가 이름 순서로 붙이므로 `02_data`의 `CHARS`·`03_systems`의 `WD`·`01_sprites`의 `ITEMS` 다음, `04_meta`의 과업 만들기 전). 엔진은 「갈래 칸 수 = 5」라고 가정한 곳만 「그 갈래의 `tiers.length`」로 바꾼다.

**기술**: HTML 한 장 + canvas 2D(외부 라이브러리 없음), `python3 build.py`, 시험은 `tests/harness.js`(Node 가짜 화면)와 Playwright.

**설계**: `docs/specs/2026-11-02-6차-전직.md`

## 지킬 것 (설계서에서 그대로)

- 6차는 **5차를 마친 퇴마사가 Lv 60 이상**일 때. 5차 전이면 뜨지 않음. 5차를 Lv 60 넘어서 마쳤으면 다음 레벨업에 뜸.
- 6차 기술은 `type:'c'` 직업 기술, `max:5`, 레벨업 카드로 올림. 피해는 `hurt` 한 곳.
- 6차 기술 하나의 피해 비중 ≤ 30%. 보스 초당 상한 그대로.
- 허준 「백 첩 탕약」 회복은 설화 「회복 없음」 규칙(`noHeal`)에서 0.
- 박문수 「봉고파직」은 보스를 묶지 않음. 이순신 「울돌목 회오리」는 보스를 끌지 않음.
- 과업 보상 엽전 300. 저장 형식 그대로.
- 6차 칸이 없는 갈래(이번 판의 무당·기생·상인)는 5차에서 멈춤. 도감 6차 줄은 「곧」.
- 인물 이름(6차 칭호): 다산 정약용 · 어사 박문수 · 구암 허준 · 신의 백광현 · 충무공 이순신 · 홍의장군 곽재우.
- 화면 버전 `v19.0`, `sw.js` CACHE `joseon-v19.0`. LOG·README 고침. 커밋·푸시는 보고 뒤 허락.

## 놓치기 쉬운 곳 (시험으로 묶음)

1. **6차 창과 각성 창이 같은 레벨대에 겹침**(Lv 58·62 각성, 60 전직) → 대기열에서 6차가 먼저 열리고 각성도 빠짐없이 열림 — 작업 1 시험 `tier6: 60과 62 사이 창 순서`.
2. **6차 칸이 없는 갈래가 Lv 60을 넘김** → 전직 창이 비거나 오류가 나지 않음, 대기열에 `adv`가 쌓이지 않음 — 작업 1 시험 `tier6: 칸 없는 갈래`.
3. **설화 출정(시작 Lv 14, 전직 단계가 정해져 있음)에서 Lv 60 도달** → 본편과 같이 전직 — 작업 1 시험 `tier6: 설화`.
4. **판 도중 언어 바꾸기** → 6차 이름·소개·기술 설명이 간체로 다시 그려짐 — 작업 4 `i18n_switch`·`i18n_cover`.
5. **6차 기술 묶기·끌기가 보스·엘리트·옹기(prop)에 걸림** → 보스는 안 묶이고 안 끌림, 옹기는 그냥 깨짐 — 작업 2·3·4 각 기술 시험.
