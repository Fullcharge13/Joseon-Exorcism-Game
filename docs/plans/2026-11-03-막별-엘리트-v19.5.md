# 막별 엘리트 v19.5 · 작업 계획 (6~10막 + 도감·과업 + 균형)

**목표**: v19.4의 틀 위에 6~10막 새 엘리트 다섯 종(여귀·흑룡·바닷속 큰 메기·삼두구미·화마)을 넣고, 도감 68·과업을 마무리한 뒤, 자동 플레이로 열 종의 세기를 맞춘다.

**구조**: v19.4와 같다. 내용은 `src/js/06b_elite2.js`에만(`addElite2`, `ELITE_AI.<행동>`, `STAGES[i].elite2`). 엔진은 꼭 필요한 곳만 고친다: 흑룡의 어둠(그리기 한 겹), 화마의 드므(표시물 + 받는 피해 배율), 삼두구미의 다시 일어남(처치 직전 갈래 하나).

**설계서**: `docs/specs/2026-11-03-막별-엘리트.md` (3장 6~10막, 5장 도감·과업, 6장 성공의 증거) · 앞 판 계획: `docs/plans/2026-11-03-막별-엘리트-v19.4.md`

## 지킬 것 (설계서에서 그대로)

- 시작값: 여귀 장판 1초마다, 5초 뒤 사라짐, 동시 ≤ 8 / 흑룡 10초마다 4초 어둠, 가운데 반지름 90은 보임, 요괴 탄·경고·피해 숫자는 늘 위 / 큰 메기 끌어당김 3초 ↔ 밀쳐 냄 3초, 세기 = 보스 끌어당김 × 0.5, 보스가 끌어당기는 동안(`G.pull`) 쉼 / 삼두구미 쓰러지면 머리 하나 잃고 체력 50%로 한 번 다시 일어남, 상자·퇴치 수는 두 번째에 한 번 / 화마 불 장판 2초마다, 4초 뒤 사라짐, 동시 ≤ 6, 드므 곁(반지름 30)에 오면 장판이 꺼지고 받는 피해 ×1.5
- 행동 전 경고 0.6~1초 · 보스는 대상 아님 · 얼면 행동 멈춤 · 쓰러지면 남은 행동(경고·끌기·어둠)을 거둠(v19.4 검토 교훈)
- 그림 12×16 세 장, 다듬기·어두운 테두리. 삼두구미는 머리 셋·꼬리 아홉(다시 일어난 뒤는 머리 둘 그림으로 바뀜) — 생김새는 지어낸 것
- 도감 63 → 68, 「도감 완성」(`dogam58`) 목표 58 → 68(이미 이룬 저장은 그대로, 아이디는 그대로), 새 과업 `elite2_all` 「요괴 사냥꾼」(새 엘리트 10종 모두 퇴치, 엽전 300)
- 설화 출정은 기존 엘리트(v19.4 결정) · 버전 `v19.5` · 커밋은 보고 뒤 허락

**결정(계획에서 정함)**: 드므는 길을 막는 장애물이 아니라 바닥에 놓인 표시물로 둔다. 지형 장애물은 좌표에서 저절로 생기는 방식이라 화마가 나올 때만 놓기 어렵고, 막는 물체가 되면 퇴마사·요괴 길찾기가 바뀐다. 설계서의 「장애물 2개」를 「표시물 2개(부서지지 않음, 지나갈 수 있음)」로 읽는다. 틀리면: 드므 뒤에 숨는 재미가 없다.

## 놓치기 쉬운 곳 (시험으로 묶음)

1. 흑룡이 어둠을 건 채 쓰러지거나 막이 바뀜 → 어둠이 남음 — 작업 1 시험
2. 큰 메기 끌어당김과 보스 끌어당김(`G.pull`)·밀쳐 내기 축복이 겹침 → 퇴마사가 튀어 나감 — 작업 2 시험: 보스 끌기 중에는 메기 힘 0, 한 프레임 이동 상한
3. 삼두구미가 한 번에 큰 피해로 두 번 쓰러짐(분열·연쇄 처치) → 다시 일어나지 않고 상자 둘 — 작업 2 시험: 다시 일어남은 정확히 한 번, 상자 1, 퇴치 수 1
4. 화마의 받는 피해 ×1.5가 드므를 떠나도 남음, 다른 화마·보스에게도 걸림 — 작업 3 시험
5. 여귀·화마 장판이 상한을 넘거나, 쓰러진 뒤에도 새로 생김 — 작업 1·3 시험

## 검토 초점

1. 흑룡 어둠과 「분위기 효과」 밤 어둠이 겹칠 때 화면이 너무 어두워 탄이 안 보임 — 작업 1 시험: 겹쳐도 탄 둘레 밝기가 `vfx_read` 기준(끈 때의 90%) 안
2. 큰 메기가 퇴마사를 화면 밖 장애물 안으로 밀어 넣음 — 작업 2 시험: 밀쳐 낸 뒤 `pushOut` 자리와 같음
3. 삼두구미가 설화·끝없는 밤·「쌍신」 연쇄 처치(`G._dg`)에서 다시 일어남을 건너뜀 — 작업 2 시험
4. 화마 드므가 보물 상자·떡과 같은 자리에 놓여 줍기를 막음 — 작업 3 시험: 드므는 줍기와 무관(표시물)
