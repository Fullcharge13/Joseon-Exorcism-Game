# 그림 다듬기 v20.5 작업 계획

**목표**: 「그림 다듬기 켬」을 색조 이동·두 색 테두리(은은하게)로 바꾼다. 끄면 예전과 한 점도 같다.
**구조**: `src/js/01_sprites.js`의 `refinePix`만 바꾸고, 색 도구 셋(`rgbToHsl`·`hslToRgb`·`hueShift`)을 같은 파일에 둔다. 다듬은 그림은 처음 쓸 때 한 번 만들어 둔다(지금과 같음).
**설계서**: `docs/specs/2026-11-03-그림-다듬기-v20.5.md` (1부 그림 규칙 · 2부 구조·성능·설정·확인 승인됨)

## 지킬 것
- 판 번호는 `GAME_VER` 한 곳 · `src/` 고친 뒤 `python3 build.py` · 커밋은 사용자 허락 뒤
- 시험 먼저(고치기 전 실패 확인) · 기계가 다시 시작되지 않게 브라우저 시험은 하나씩

## 살필 것
1. 한 칸 무늬(입·볼·단추)가 가장자리에 있을 때 색이 바뀜 → 작업 1 「한 칸 무늬 그대로」
2. 짙은 칸(밝기 < 60)이 가장자리에서 바뀜 → 작업 1 「짙은 칸 그대로」(기존 시험 유지)
3. 「끔」 화면이 바뀜 → 작업 3 `refine_same`
4. 그림 만드는 시간이 늘어 출정 시작이 느려짐 → 작업 3 `refine_perf` 1.5배 이내
5. 흰색·회색처럼 색조가 없는 색이 엉뚱한 색으로 물듦 → 작업 1 「무채색은 채도 0 그대로」

### 작업 2: `refinePix` 새 규칙
