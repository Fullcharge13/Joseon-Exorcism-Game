# 다국어 v18.1 · 작업 계획 (간체 중국어)

- **목표**: 게임 전체를 간체로 막힘없이 즐길 수 있게 한다. 한국어 화면은 v18.0과 같다.
- **구조**: 번역은 `src/i18n/zh/*.json`(영역별 「한국어 원문 → 中文」)에 두고, `build.py`가 `Object.assign(I18N.zh, …)`로 합쳐 넣는다. 원문 목록은 `tools/i18n_keys.py`가 뽑는다(데이터 표 문자열 + 코드의 `_t` 열쇠 + 화면 틀 글).
- **설계**: `docs/specs/2026-10-24-다국어.md` · **용어집·말투**: `docs/i18n/용어집.md`
- **지킬 것**: 용어집 고정 번역, `{변수}`·태그·숫자 보호, 간체 화면 한글 0자, 번체·가나 없음, 한국어 회귀 0(`i18n_ko_same`), 화면 버전 `v18.1`
- **커밋**: 마무리 보고 뒤 허락

## 검토 때 특히 볼 곳

1. 번역이 빠진 원문(특히 실행 중에 조립되는 표 문자열: 직업 과업, 합공 설명) → `i18n_cover`
2. 끼워 넣을 자리·태그가 어긋나 화면이 깨짐 → `i18n_cover` 「보호 부분 같음」
3. 간체 화면에 한글이 남음(캔버스 글·알림·도움말 그림 속 글) → `i18n_zh_flow.py`
4. 글이 길거나 글꼴이 없어 넘치거나 네모로 깨짐 → `i18n_zh_flow.py` 넘침·글꼴 검사
5. 기록관 옛 기록이 언어를 바꾸면 다른 언어로 남음 → `i18n_arch`

## 작업 1 · 원문 목록과 시험 (실패 확인)

- [x] `tools/i18n_keys.py`: 원문 전체를 `docs/i18n/원문.json`(원문, 나온 곳)으로
- [x] 단위 `i18n_cover`: 모든 원문에 간체가 있음 · 간체에 한글 0 · `{이름}` 집합이 원문과 같음(조사 표시는 빼고 비교) · `<태그>` 개수가 같음 · 숫자(%·+·×)가 원문에 있으면 간체에도 · 용어집 고정 번역 지킴
- [x] 단위 `i18n_arch`: 기록관 기록을 언어와 상관없이 다시 만들 수 있음(아이디 저장), 옛 기록(완성된 글)도 깨지지 않음

## 작업 2 · 번역 (영역별)

화면 틀 → 퇴마사·전직 → 무기·기술·합공 → 보패·신령·점괘·담금질·인장 → 요괴·막·보스 → 과업 → 식구·대사·안내인 → 설화·결말 → 도움말 → 코드 문구(화면 함수·알림)
- 영역마다: 번역 → `i18n_cover`의 그 영역 통과
