# 분위기 층 v18.3 · 작업 계획 (흔들리는 풀 · 막별 날씨)

- **목표**: 바람에 흔들리고 밟으면 눕는 풀, 막마다 하나의 보기만 하는 날씨. 규칙·밸런스 그대로.
- **구조**: `src/js/08c_vfx.js`의 막별 표 `STAGE_VFX`에 `grass`(풀 색 셋, 없으면 null)·`weather`를 더한다. 풀은 바닥 뒤 `vfxGround`에서(흔들림 5단계를 미리 그린 그림), 날씨는 `vfxLight` 안 어둠 다음·빛 번짐 전에. 날씨 입자는 상태 없이 번호·시각으로 자리를 계산(저장·할당 없음).
- **설계**: `docs/specs/2026-11-01-분위기-층.md` 3장(날씨 열) · 사용자 결정: 날씨 A(보기만)
- **지킬 것**: 요괴 탄·경고·숫자는 날씨 위(그리는 순서가 이미 위) · 날씨 입자 ≤ 120(약하게 60, 절약 0) · 절약 모드에는 풀·날씨 없음 · 돌바닥 막(5·10)은 풀 없음 · 게임 난수 안 씀 · 화면 버전 `v18.3`
- **커밋**: 마무리 보고 뒤 허락
