# 성황당·괴이·샛길 안내인 · 작업 계획 (v17.5)

- **목표**: 세 장소에 상징물·안내인·말풍선·가장자리 표지를 더해 눈에 띄고 이끌게 한다. 동작·보상은 그대로.
- **구조**: 내용은 `GUIDE`(문구·자리·빛깔)·`GNPC`(도트)·`GICON`(표지 아이콘) 표에 두고, 말하는 순간은 `guideSay` 한 함수가 정한다. 화면 글은 `drawGuideUI`가 화면 캔버스에 그린다.
- **기술**: `index.html` 한 장. 시험은 `tests/harness.js`, Playwright.
- **설계 문서**: `docs/specs/2026-10-24-장소안내인.md`
- **지킬 것**: 순간마다 한 번 · 문구는 표 안에서만 · 머무는 시간·판정·보상 그대로 · 말풍선 화면 글자 12~18px · 절약 모드면 흔들림만 멈춤 · 저장 형식 그대로 · 화면 버전 `v17.5`, `sw.js` `joseon-v17.5`
- **커밋**: 마무리 보고 뒤 허락을 받는다.

## 검토 때 특히 볼 곳

1. 말풍선이 남아 다음 막·다음 장소에 엉뚱하게 뜸 → 작업 1 `guide_clear`
2. 같은 순간을 매 장면 말함(대기열 폭주) → 작업 1 `guide_say` 「두 번 말하지 않음」
3. 동작이 바뀜(머무는 시간, 판정, 보상 순서) → 작업 1 `guide_same`
4. 말풍선이 화면 밖으로 나가거나 퇴마사를 덮음 → 작업 3 `guide_ui.py`
5. 도움말 그림(실제 그리기 함수로 잘라 낸 성황당 등)이 깨짐 → 작업 4 `help_imgs.py`
