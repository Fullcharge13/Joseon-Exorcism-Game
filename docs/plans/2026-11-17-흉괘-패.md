## 살펴볼 것(시험이 놓치기 쉬운 것)
1. 옛 저장·옛 판 기록(`card` 한 장 글자)으로 다시 하기 → 흉괘 없이 정상 (hyung.test)
2. 공망 + 운(luck) 없음 → 선택지 2장이어도 레벨업 창이 열림 (hyung.test: openPick 카드 수 ≥ 2)
3. 상문살 경고가 무더기 처치(폭발 무기)에서 60개를 넘지 않음 (hyung.test)
4. 귀문관살 + 흑룡 어둠이 겹쳐도 그림 오류 없음 (브라우저 캡처)
5. 설화 출정(tale)에는 흉괘가 없음 — 준비 화면에서 설화 모드일 때 흉괘 묶음 숨김 (브라우저)
