# 견습 동행 설계 (2부 제11막부터)

> 작성 2026-11-23 · 사용자 승인 「진행」(설계 대화의 답 4개 반영) · 계획 `docs/plans/2026-11-23-견습-동행.md`
> 상태: **구현됨(v22.1)**. 구현 중 바뀐 것은 맨 끝 「구현 메모」(특히 균형 목표).

## 왜
자동 플레이 기록(v22.0 최종 24판): 9막에 들어설 때 이미 무기 10칸·보패 4칸이 모두 최고, 「다 찬 비율」 9막 86% → 15막 91%. 11막부터 레벨이 20 오르는 동안 고를 것이 거의 없다. 2부에 **새로 키울 대상**을 둔다.

요청(원문): 「소년 (근접 공격) / 소녀 (원거리 공격), 퇴마사의 근처에서 머물며 다가오는 요괴를 공격합니다. / 소년/소녀는 레벨업시 두 개의 무기 옵션이 주어지며, 무기 하나 & 보패 하나만을 선택할 수 있습니다. / 소년/소녀가 체력이 다하면 쓰러져 퇴마사가 근처로 와 5초간 머물며 치료해 줍니다. 그 이후 소년/소녀는 다시 싸울 수 있습니다. 3번째 쓰러짐에서 퇴마사가 숨겨주기 스킬을 사용하여 다음막까지 피해를 입지 않고 숨어 있을 수 있습니다.」

## 정한 것
| 물음 | 답 |
|---|---|
| 성장 규칙 | 견습은 무기 1칸·보패 1칸. 퇴마사 레벨업 카드 가운데 둘이 견습 카드(지금 것 Lv+1 또는 다른 것으로 바꾸기) |
| 무기 출처 | 견습 전용 새 무기(소년 근접 3 · 소녀 원거리 3) · 공용 보패 4 |
| 쓰러짐 횟수 | 막마다 새로(막이 바뀌면 체력 가득 · 0번부터) |
| 치료 | 견습 둘레 원 안에 퇴마사가 있으면 5초 막대가 차오름, 밖이면 멈춤(줄지 않음). 치료 중에도 퇴마사 무기는 그대로 |
| 요괴 | 지금처럼 퇴마사만 쫓음. 견습은 요괴 몸·탄·장판·경고에 맞으면 체력이 줆 |
| 숨겨 주기 | 한 막에서 세 번째로 쓰러지면 저절로(단추 없음). 다음 막 시작에 돌아옴 |

## 이야기·표현 원칙
- 1부에서 지나온 마을의 아이가 「퇴마를 배우는 견습」으로 따라나선다. 퇴마사가 지켜 주는 관계.
- 쓰러짐은 **기절**(머리 위 별)로만 그린다. 다치는 연출·피는 없다. 숨겨 주기는 덤불 뒤로 숨는 표현.
- 이름: 소년 「복돌」, 소녀 「연이」(흔한 옛 아이 이름 꼴의 가상 인물, 실존 인물 아님).

## 흐름
```
제10막 평정 → 판의금부사 전갈 → 「북으로 간다」
  → (처음이면) 견습 장면 2쪽 → 견습 고르기: 복돌(근접) / 연이(원거리)
  → 주막 → 제11막(견습: 목검 또는 새총 Lv1, 체력 가득)
끝없는 밤으로 이어 가도 견습은 계속 따라온다. 설화 출정·원정·1부만 하는 판에는 없다.
```

## 견습
- 체력 기본 160(보패 복주머니로 늘어남). 맞은 뒤 1.2초 무적. 받는 피해는 요괴 피해의 0.15배(복돌이 요괴 몸에 닿을 땐 그 절반).
- 움직임: 퇴마사에서 40 안에 머문다. 소년은 퇴마사 70 안의 가장 가까운 요괴 쪽으로 붙어 싸우되 퇴마사에서 60을 넘지 않음. 소녀는 퇴마사 곁 30 남짓에서 쏜다.
- 피해는 `hurt`로만, 출처 `ap:<무기 id>`로 기록(피해 비중 표에 나옴). 치명타 없음(`noCrit`).
- 피해 크기 = 최근 20초 초당 피해(모든 출처) × 재사용 × 무기 몫 × 8%(Lv1)~16%(Lv5) × (1 + 댕기). 보스에게는 퇴마사와 **따로** 초당 상한(퇴마사 상한의 10%~32%)을 가진다. 보스가 닿으면 보스부터 노린다.

| 무기 | 누구 | 동작 |
|---|---|---|
| 목검 | 소년 | 가까운 요괴 쪽 부채꼴 휘두르기 |
| 도리깨 | 소년 | 제자리 한 바퀴 휘둘러 둘레 모두 |
| 장대 | 소년 | 한 줄로 길게 찌르기(꿰뚫음) |
| 새총 | 소녀 | 가까운 요괴에게 돌 한 발 |
| 대나무 활 | 소녀 | 화살 한 발, 셋까지 꿰뚫음 |
| 물총 | 소녀 | 짧은 물줄기 세 갈래, 맞은 요괴 1초 느려짐 |

| 보패 | 효과(Lv마다) |
|---|---|
| 짚신 | 공격 빠르기 +8% |
| 복주머니 | 최대 체력 +20% · 막이 바뀔 때 말고도 초당 1 회복 |
| 방울 | 범위 +10% |
| 댕기 | 피해 +12% |

## 레벨업 카드
- 견습이 있으면 레벨업 선택지 가운데 **두 칸이 견습 카드**(나머지는 퇴마사). 견습 카드는: 지금 무기 Lv+1(최대 5) · 같은 갈래의 다른 무기로 바꾸기(Lv는 지금 Lv−1, 최소 1) · 보패 새로/ Lv+1(최대 5) · 다른 보패로 바꾸기. 모두 최대이면 「견습 단련: 피해 +5%」(끝없이).
- 카드 꼬리표 「견습」, 아이콘은 글자 도장.

## 쓰러짐·치료·숨겨 주기
- 체력 0 → 기절, `downs`+1. 둘레 26 원과 치료 막대 표시. 퇴마사가 원 안에 있으면 1초에 0.2씩 차서 5초 → 체력 50%로 일어남.
- 한 막에서 세 번째 기절이면 곧바로 숨겨 주기: 견습이 사라지고 「○○를 덤불 뒤에 숨겼다」. 그 막에서는 피해도 공격도 없다.
- 막이 바뀌면(`nextStage`) 체력 가득, `downs` 0, 숨음 풀림.

## 화면
- 견습 머리 위 작은 체력 막대(기절이면 치료 막대).
- 왼쪽 위 무기 칸 줄 앞에 견습 칸 둘(무기·보패 글자 도장 + Lv).

## 균형
- 목표: 견습 피해가 전체의 15~25%(한 출처 30% 이하). 2부 막 보스 시간 20~60초 유지.
- 측정: 같은 장면 보스전(견습 있음/없음)과 자동 플레이(봇은 기절한 견습 곁으로 가도록 한 줄 더함).

## 시험
`ap_flow`(등장·고르기·11막 시작) · `ap_cards`(레벨업 두 칸·올리기·바꾸기·최대 뒤 단련) · `ap_down`(기절·원 밖이면 멈춤·5초 치료·세 번째 숨겨 주기·다음 막 복귀) · `ap_fight`(무기 6종이 저마다 피해>0, 출처 기록) · `act2_off_same`(1부 그대로) · 옛 저장.

## 구현 메모 (v22.1)
- **균형 목표를 바꿈**: 「견습 피해 15~25%」는 닿을 수 없었다(11막 퇴마사는 일반 요괴에게 초당 약 77,000 피해 — 화면을 쓸어 담는 무기가 대부분이고, 보스는 초당 상한을 퇴마사가 다 씀). 조정 세 번(고정 수치 → 퇴마사 초당 피해에 맞춤 → 모든 출처 초당 피해에 맞춤) 모두 0.2~2%. 그래서 견습의 역할을 **보스전 조력자**로 정하고 목표를 「보스 처치 시간 단축」과 「막당 기절 1번 안팎」으로 바꿈.
- 보스 따로 상한(조정 3) + 보스 먼저 노리기 + 화살·물줄기는 노린 보스에게 닿음: 같은 장면(퇴마사가 상한을 꽉 채움)에서 보스 처치 시간 Lv1 −5~6%, Lv5·댕기5 −10~24%.
- 내구(사용자 결정 「보스에게서 거리 두기 + 받는 피해 절반」): 보스 몸에서 소년 r+14·소녀 r+40, 곧 터질 경고 장판 밖으로 비킴, 받는 피해 0.3 → 0.15. 그래도 막당 기절 복돌 3·연이 1.75 → 체력 120 → 160·무적 0.6 → 1.2초 → 복돌 2.0·연이 0.6 → 복돌의 몸 닿는 피해 절반 → 복돌 1.0.
- 기절 알림은 휴대폰 폭에 맞게 짧게(「연이가 쓰러졌다 · 곁에서 5초」).
