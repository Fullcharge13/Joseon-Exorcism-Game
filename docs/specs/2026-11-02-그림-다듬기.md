# 그림 다듬기 설계 (v18.6)

- 날짜: 2026-11-02 · 상태: 사용자 확인(「진행」)
- 요청: 「B-1 (추천): 자동 다듬기」 — 캐릭터·요괴 그림을 손으로 다시 그리지 않고, 코드가 테두리·위 밝게·아래 어둡게를 자동으로 입힌다. 켬/끔 설정.
- 사용자 결정: 테두리 B(맞닿은 색을 어둡게) · 범위 A(움직이는 것 전부) · 설정 A(따로 「그림 다듬기」 켬/끔, 기본 켬)
- 시안(버리는 시험판, 2026-11-02): 그림 77장 다듬기에 시작 때 약 4ms, 게임 중 비용 0. 문제 둘 — 가장자리에 빈칸 없는 그림은 테두리가 잘림(→ 둘레 1칸 여백), 검은 갓이 회색이 되고 챙과 갓 사이 틈이 메워짐(→ 짙은 색은 밝히지 않음, 안쪽 틈은 메우지 않음)

## 1. 목표와 지킬 것

- 퇴마사·요괴·보스·펫·동료가 바닥에서 또렷하게 떠 보이게. **보기만 바뀐다**: 맞는 범위·크기 계산(`s.w`, `s.hgt`)·체력 막대 자리·규칙·밸런스 그대로.
- 떨어진 물건·카드 아이콘·방패·장판은 다듬지 않는다.
- 게임 중 무게는 늘지 않는다(미리 만들어 두고 고르기만).

## 2. 다듬기 규칙 (그림 한 장)

1. 둘레에 1칸 여백을 둔 새 캔버스(가로·세로 +2)에 원래 그림을 (1,1)에 놓는다.
2. **바깥 빈칸**: 여백 테두리에서 시작해 빈칸만 따라 퍼진(4방향) 칸. 그림 안에 갇힌 빈칸(1칸 틈 포함)은 바깥이 아니다.
   - (구현 전 보탬) 바깥 빈칸이라도 좌우 둘 다 또는 위아래 둘 다 그림 칸인 1칸 골목(예: 갓 챙과 갓 사이)은 테두리를 칠하지 않는다.
   - (구현 중 보탬, 캡처 확인 뒤) 짙은 색(밝기 60 미만)에만 닿은 바깥 칸은 테두리를 칠하지 않는다. 검은 갓 둘레가 한 칸 두꺼워져 뭉개 보였음. 평균 색도 짙은 칸은 빼고 낸다.
3. **테두리**: 바깥 빈칸 가운데 위·아래·왼쪽·오른쪽에 그림 칸이 맞닿은 칸. 색은 맞닿은 그림 칸들 색의 평균 × 0.45(어둡게), 불투명.
4. **위 밝게**: 바로 위가 바깥 빈칸인 그림 칸은 흰색 쪽으로 18%. 단 밝기(0.2126R+0.7152G+0.0722B)가 60 미만인 짙은 색은 그대로.
5. **아래 어둡게**: 바로 아래 또는 바로 오른쪽이 바깥 빈칸인 그림 칸(위 밝게가 아닌 칸)은 × 0.8.
6. 하얀 번쩍임 그림(`h`, `hf`)은 다듬은 그림에서 만든다(테두리까지 흰색).

## 3. 구조

- `src/js/01_sprites.js`의 `variants(c)` 한 곳: 원래 네 장(`n f h hf`)과 다듬은 네 장을 함께 만들어, `n f h hf`와 `pad`(0 또는 1)는 설정에 따라 고르는 속성으로 돌려준다. `w`, `hgt`는 원래 크기 그대로.
- 그리는 함수 `drawSpr`는 `pad × 배율`만큼 왼쪽·위로 옮기고 가로·세로를 `(w+2pad)·배율`로 그린다 → 발 자리(아래 가운데)가 끔과 같다.
- 화면 그림(도감·직업 고르기·설화 장면·펫 칸)은 `.n`을 쓰므로 자동으로 따라간다. 설정을 바꾸면 도감 그림 저장(`HELPIMG`)을 비운다.
- 다듬을 그림: `variants`를 거치는 것 전부(퇴마사·전직 외형·요괴·보스·펫·포졸·동료). 다른 그림(아이콘 `ICS`, 방패, 물건)은 `variants`를 쓰지 않으므로 그대로.
- 설정 `meta.set.refine` = `'on'|'off'`, 기본 `'on'`. 옛 저장·엉뚱한 값 → `'on'`(`normSet`). 설정 화면 「그림 다듬기」 줄(켬/끔), 간체 번역.

## 4. 성공의 증거

| 시험 | 기대 |
|---|---|
| 단위 `refine_rule` | 시험 그림(ㄷ자 + 안쪽 1칸 틈 + 검은 칸): 바깥 빈칸만 테두리 · 안쪽 틈은 빈칸 · 테두리가 맞닿은 색보다 어두움 · 검은 칸은 위에 있어도 그대로 · 다듬은 그림 크기 w+2·h+2 · `w`·`hgt`는 원래 값 |
| 단위 `refine_set` | 기본·옛 저장·엉뚱한 값 → 'on' · 끔이면 `pad` 0이고 `.n`이 원래 캔버스 · 켬이면 `pad` 1 |
| 브라우저 `refine_same` | 「끔」 화면이 v18.5와 한 점도 다름 없음(10막 같은 장면) · 「켬」에서 퇴마사·요괴 아래 가운데 발 자리가 끔과 같음 · 화면 오류 0 |
| 캡처 | 10막 × 켬·끔 × PC·휴대폰, 도감·직업 고르기 |
| 기존 시험 | 단위 전부(`ent_size` 포함), 브라우저 14종, 자동 플레이 12판 오류 0, `vfx_perf` 기준 안 |

## 4-1. 구현 중 바뀐 것 (검토 뒤)

- 뒤집힌 그림(`f`, `hf`)은 원래 그림을 뒤집은 뒤 따로 다듬는다(어느 쪽을 보든 아래·오른쪽이 어둡게). 다듬은 네 장은 처음 쓸 때 만든다.
- 실제 브라우저에서 다듬기가 실패하면 `REFINE_ERR`에 모으고 다듬지 않은 그림(여백만)으로 그린다. 점 읽기가 없는 시험용 가짜 화면에서만 조용히 건너뛴다.
- 설정을 바꾸면 도감 그림(`HELPIMG`)과 과업 휘장(`badgeCache`) 저장을 비운다.
- 몸 대부분이 검은 그림은 테두리가 보이지 않아 사실상 그대로다(규칙대로).

## 5. 하지 않는 것

- 손으로 그림을 다시 그리기, 그림 해상도 올리기, 아이콘·물건 다듬기, 다듬기 세기 단계.
