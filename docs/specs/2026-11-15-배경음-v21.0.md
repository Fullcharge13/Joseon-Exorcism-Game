# 배경음 v21.0 설계 (막마다 국악풍 배경음 · 보스 때 빨라짐 · 본부 곡)

- 날짜: 2026-11-15 · 상태: 조사(A 코드로 작곡) → 시험곡 1·2·3판 → 구상 질문 1~3 · 설계 1~3부 승인 → 설계서
- 결정 기록:
  - 조사 「막마다 어울리는 배경음 — 무료 소스나 생성」 → A 코드로 국악풍 작곡(무료 음원은 조선 분위기 곡이 드물고, 공개 저장소에 원본을 올리는 라이선스 문제)
  - 시험곡 2판 요청: 「1막에서 10막까지 갈 때 리듬이 조금씩 더 빨라지지만 스테이지의 배경을 반영하면서도 조금 더 어두운 느낌」
  - 시험곡 3판 요청: 막마다 주변 소리(1 도망가는 사람들의 비명 · 2 대숲 바람 · 3 호랑이 · 4 비 · 5 불경 · 6 죽어가는 사람들 · 7 강한 바람 · 8 파도 · 9 저승의 고통받는 목소리 · 10 병사들 죽어가는 소리), 「볼륨을 최대한 약하지만 배경음에 묻어갈 수 있도록」
  - 질문 1 「가 보스 때 같은 곡을 더 빠르고 세게」 · 질문 2 「가 본부 곡 하나 + 다른 방식은 막 곡 재사용」 · 질문 3 「가 미리 만든 음원 파일」(게임 안에서 만들면 한 곡 4~11초 — 측정)

## 1. 곡

| 곡 | 개수 | 내용 |
|---|---|---|
| 막 곡 `s01`~`s10` | 10 | 시험곡 3판: 계면조 · 빠르기 72→132박 · 장구 2.4→6.0회/초 · 막 장소 소리 · 주변 소리는 음악보다 15dB 아래(±1) |
| 보스 판 `b01`~`b10` | 10 | 같은 막 곡을 빠르기 ×1.15, 장구·징 세게(장단 한 단계 몰아침), 주변 소리 그대로 |
| 본부 곡 `hub` | 1 | 느린 가야금 산조풍(진양조), 대금 조금, 주변 소리 없음 |

- 한 곡 약 48초 = 장단이 딱 끝나는 길이. 끝의 잔향을 앞에 겹쳐(접어서) 반복 이음새가 매끄럽게
- 모노 · mp3 96kbps(아이폰·안드로이드·PC 모두) · 합계 약 10MB
- 파일 이름에 내용 지문(`s01-1a2b3c.mp3`) → 곡이 바뀔 때만 새로 받음
- `audio/bgm/bgm.json`: `{id: {file, sec, loopStart, loopEnd}}`

## 2. 도구

- `tools/bgm/compose.js`(시험곡 코드 정리: 악기·장단·막 설정·주변 소리·보스·본부) · `python3 tools/bgm.py`가 실제 브라우저(OfflineAudioContext)로 21곡을 만들고 ffmpeg로 mp3
- 주변 소리 크기는 곡마다 음악만·주변만을 따로 재어 15dB 아래로 맞춤 · 같은 입력 → 같은 파일
- 끝에 보고: 곡마다 길이·장구 횟수·주변 소리 차이·이음새 튐(끝·처음 점 차이)

## 3. 게임 안 동작

**「지금 들려야 할 곡」 하나로 정함** — `bgmWanted(상태)` → `{id, gain}`을 1초에 네 번 보고, 바뀌면 2초 동안 앞 곡을 줄이며 새 곡을 키움. 일이 일어나는 곳(막 시작·보스 처치 등)마다 따로 끼우지 않아 빠뜨림이 없음

| 상황 | 곡 · 크기 |
|---|---|
| 시작 화면·본부·설정 등 판 밖 | `hub` |
| 판 안(본편·설화 출정) | 그 막 `s0n` |
| 끝없는 밤 | 막 번호를 10으로 돌림(11막 → `s01`) |
| 막 보스가 나와 있음 | `b0n` (중간 보스는 막 곡 그대로) |
| 레벨업·정지·보상 등 창 | 같은 곡 × 0.5 |
| 판 결과 화면(끝남) | 꺼짐(2초) |
| 「배경음」 0 · 음소거 | 꺼짐(0이면 받지도 않음) |

- 설정에 **「배경음」 크기 0~100(처음 60)** — 「효과음」과 따로 · 옛 저장은 60이 들어감(설정 기본값 합치기)
- 아이폰: 첫 터치에 소리 시작(지금 효과음과 같은 `initAudio`)
- 받기: 막에 들어갈 때 그 곡을 받아(`fetch` → `decodeAudioData`) 받는 대로 서서히 키움 · 보스 판과 다음 막 곡은 미리 받음 · 한 번에 3곡까지만 들고 있음(메모리)
- 게임이 가려지면(앱 전환·화면 끄기) 멈추고 돌아오면 이어서 — 지금의 `onVisibility`에 맞춤
- 받기·풀기 실패(오프라인·오래된 기기)는 조용히 넘어감, 오류 기록에 한 번만 「배경음 못 받음」

## 4. 오프라인 (`sw.js`)

- `audio/` 요청은 **판 번호와 따로 두는 저장소**(`jtm-bgm`)에 저장 · 있으면 저장본(캐시 먼저) — 판이 올라가도 다시 받지 않음, 지문이 바뀐 곡만 새로
- 저장소에 없고 인터넷도 없으면 404(지금처럼 게임 화면을 돌려주지 않음)
- 오래된 지문 파일은 새 `bgm.json`에 없는 것을 지움

## 5. 확인 (시험 먼저)

| 시험 | 보는 것 |
|---|---|
| 단위 `bgm_wanted` | 판 밖 `hub` · 판 안 막 곡 · 보스 판 · 보스 처치 뒤 막 곡 · 끝없는 밤 11막 `s01` · 설화 출정 막 곡 · 창이면 ×0.5 · 결과 화면 꺼짐 · 「배경음」 0이면 꺼짐·받지 않음 · 음소거 꺼짐 |
| 단위 `bgm_settings` | 옛 저장(배경음 없음)으로 시작 → 60 · 크기 바꾸면 저장됨 (구현 때 `bgm_wanted` 시험에 함께 넣음) |
| 도구 `tests/browser/bgm_tool.py` | `bgm.json`의 21곡 파일이 모두 있음 · 길이 = 장단 배수 · 주변 소리 차이 15±1dB · 이음새 튐이 곡 안의 보통 점 차이보다 크지 않음 · 두 번째 실행에서 바뀐 파일 0 |
| 브라우저 `bgm_play` | 휴대폰·PC: 터치 → 본부 곡 재생 · 판 시작 → 막 곡 · 보스 불러내기 → 2초 안에 보스 판 · 정지 창 → 크기 반 · 「배경음」 0 → 꺼짐 · 설정 칸 넘침 0 · 음악 파일을 막은 상태(오프라인 흉내)에서 오류 창 없음 · 화면 오류 0 |
| 성능 | 음악 켬/끔 화면 프레임 시간 차이(지금 `vfx_perf` 방식) — 1ms 이하 |
| 기존 | 단위 전부 · 브라우저 전부(하나씩) · 간체(새 글: 배경음 등) |

- 실제 소리 느낌·아이폰 이음새는 사용자가 휴대폰으로 확인(이 작업 환경은 들을 수 없음, 사파리 엔진 없음)
