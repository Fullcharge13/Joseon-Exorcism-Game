## 0. 정해진 것 (결정 기록)

| 질문 | 결정 |
|---|---|
| 만드는 방법 | **A + C**: 설화 출정을 출정 방식(모드)으로 두고, 본편에서 설화 조각을 모아야 열린다 |
| 조각을 얻는 곳 | 관련 막에서 나타나는 **「설화 흔적」을 조사** (괴이 조사 방식 재사용) |
| 설화 하나의 조각 수 | **3개** (시작 → 중간 → 위기 대목) |
| 한 판의 모양 | **3막, 정해진 힘으로 시작** (막마다 약 90초 + 이야기 보스, 막 사이 이야기 장면) |
| 보상 | **옷 빛깔 하나 + 결말 글**, 다시 하기는 **기록 도전**(가장 빠른 완주 시간). 능력치 보상 없음 |
| 본편 결말 | **공통 결말 장면 4장 + 퇴마사별 맺음말 한 쪽**. 뼈대: 그슨대 = 잊힌 옛이야기의 그림자 |
| 첫 묶음 설화 | 전우치전(선비) · 지하국대적(장수) · 바리공주(무당) |

## 1. 목적

- 제10막 뒤에 끝맺음이 없어 「그래서 무엇이었나」가 비어 있다 → 결말로 채운다.
- 본편을 여러 번 돌 이유(흔적 모으기)와 짧게 즐길 거리(6~8분 이야기 출정)를 함께 만든다.
- 게임에 이미 있는 요괴·인물의 원전 설화를 들려주어 「한국 요괴 도감」 게임다움을 살린다.

## 2. 플레이어가 겪는 흐름

1. **흔적**: 본편(출정 방식 「출정」)에서, 조각이 3개 미만인 설화의 「흔적 막」에 들어서면 막 시작 25~85초 사이에 금빛 흔적이 한 번 나타난다. 괴이 조사와 15초 이상 떨어지게 잡는다. 화면 가장자리에 **금색 화살표**.
2. **조사**: 흔적 곁(반지름 24)에 2.5초 머물면 조각 하나. 멀어지면 진행이 천천히 줄어든다(괴이와 같음).
3. **조각 읽기**: 게임이 멈추고 이야기 장면 창이 뜬다(인물 도트 + 글 + 「설화 조각 n/3」 + 「다음」).
4. **열림**: 3/3이 되면 장면 창 끝에 「설화 출정 『전우치전』이 열렸다」. 과업 알림과 같은 자리에도 한 번.
5. **설화 출정 고르기**: 출정 준비 → 출정 방식 「설화 출정」 → 퇴마사 고르기 대신 **설화 목록**.
   - 잠김: 「??? · 조각 1/3 · 제1막 한양 저잣거리에서 흔적을 찾자」
   - 열림: 설화 이름, 퇴마사, 한 줄 소개, 옷 빛깔 보상
   - 완주: 위 + 「가장 빠른 완주 03:41」
   - 설화 출정에서는 난이도 「보통」 고정, 점괘 패·액운·정표 고르기를 숨긴다(정해진 힘).
6. **한 판**: 시작 장면 → 1막(약 90초 뒤 보스) → 막 사이 장면 → 2막 → 장면 → 3막 → 설화 결말 장면 → (처음이면) 「선비의 쪽빛 도포가 열렸다」 → 결과 화면.
7. **옷 빛깔**: 출정 준비에서 퇴마사를 고르면 「차림: 기본 / 쪽빛 도포」. 본편·설화 출정·퇴마 원정 모두에 적용. 모든 전직 차림의 옷 색이 바뀐다.
8. **본편 결말**: 본편에서 제10막 막 보스를 처음 쓰러뜨리면 끝없는 밤 고르기 **앞에** 공통 장면 4장 → 그 퇴마사 맺음말. 이미 본 공통 장면은 다시 나오지 않고, 그 퇴마사의 맺음말이 처음일 때만 맺음말 한 쪽.
9. **설화록**: 퇴마록에 「설화록」 탭 추가. 본편 결말(공통 4장, 맺음말 6쪽) → 설화 세 편(조각 1·2·3, 설화 결말, 출처).

    trace:'scroll',            // 흔적 도트 종류
    frags:[ {t, by}, {t, by}, {t, by} ],          // 조각 글 3개, by = 장면에 세울 도트(look 또는 적 id)

- `bg`·`pool`: 배경과 일반 요괴 구성을 가져올 본편 막 번호(새 배경·새 요괴 없음).

- 실제 막 번호·색 값은 구현 때 화면을 보며 맞춘다.

| 규칙 | 설화·막 | 내용 | 근거 |
|---|---|---|---|
| `jwAlly` | 전우치 1막 | 전우치가 막 내내 곁에서 싸움(본편의 전우치 도움 `G.helper`를 막 끝까지 유지) | 창작 |
| `grain` | 전우치 2막 | 떡 대신 곡식 섬이 떨어지고, 20섬을 주우면 보스 등장 | 원전(곡식 나눔)을 규칙화 |
| `clones` | 전우치 3막 | 분신(약한 전우치 모습 적)이 섞여 나옴 | 창작 |

| `well` | 지하국 2막 | 우물 곁(반지름 30)에 있으면 공격력 초당 +6%p, 최대 +60%. 떨어지면 초당 −10%p | 원전(힘내는 물) |

| `wells3` | 바리 2막 | 우물 세 곳을 차례로 6초씩 지켜야 보스 등장 | 원전(고된 일) |

### 3-3. `ENDING`

- `ENDING.common`: 4장 `{t, art}` (3부에서 확정한 글)
- `ENDING.epi`: 퇴마사 id → 맺음말 글 (3부에서 확정한 글)

### 3-4. 저장 (`saveVer` 12 → 13)

```
meta.tale   = { frag:{woochi:0, jiha:0, bari:0}, done:{ <id>:{best:초, n:완주수} }, skin:{ <cid>:'jjok' | null } }
meta.ending = { seen:false, epi:[ <cid>, ... ] }
```

- 옮기기: `saveVer < 13`이면 위 빈 값으로 채우고 13으로 올린다. 다른 저장 값은 건드리지 않는다.
- `meta.tale.skin`에 없는 빛깔 id가 들어 있으면 기본(null)으로 바로잡는다.

## 4. 엔진 연결 (바꿀 곳)

| 곳 | 바꿈 |
|---|---|
| `MODES` | `tale:{n:'설화 출정', d:...}`. 열린 설화가 하나도 없으면 버튼은 보이되 「흔적을 모으면 열린다」 안내 |
| 출정 준비 | 모드가 `tale`이면 퇴마사 카드 대신 설화 카드, 난이도·점괘·액운·정표 숨김. 차림(빛깔) 고르기는 모든 모드에 추가 |
| `newGame(..., mode='tale')` + `taleStart(id)` | 퇴마사·갈래·전직·레벨·무기를 표대로 세팅. `G.tale={id, act:0, t0}` |
| `nextStage` | 본편: 흔적 예약(`G.traceAt`). 설화: 막을 표의 `bg/pool`로 바꾸고 막 시작 규칙 실행 |
| 막 시간 | 설화 모드에서 막 보스 등장 시각을 `STAGE_T` 120초 → 90초(또는 규칙의 보스 조건). 중간 보스(`MID_T` 60초)는 나오지 않음 |
| 보스 처치 후 흐름 | 설화 모드는 도깨비 보물·갈림길·보물 상자·주막 대신 「막 사이 장면 → 다음 막」, 3막 뒤에는 「설화 결말 → 보상 → `endGame(true)`」 |
| 본편 결말 | `openEndless` 앞에서 `G.mode==='normal'`이고 제10막 평정이면 `openEnding()`을 먼저 열고, 닫힌 뒤 기존 창 |
| 이야기 장면 창 | 새 화면 `scene`. `PICK_SCREENS`에 넣어 0.5초 입력 보호·v16.3 터치 처리를 그대로 받는다. 「다음」 하나, 숫자 키 1·스페이스·엔터로도 넘김 |
| 옷 빛깔 | `playerLook()`이 `meta.tale.skin[cid]`가 있으면 look의 `A`(옷 색)만 바꿔 돌려준다 |
| 퇴마록 | 「설화록」 탭 |
| 기록 | 설화 완주는 기록관 「출정 일지」에 「설화 · 전우치전 · 03:41」로 남김. 명예록에 「가장 빠른 설화」 |
| 과업 | `t_frag1`(첫 설화 조각, 엽전 30) · `t_tale1`(첫 설화 완주, 엽전 100) · `t_ending`(본편 결말 보기, 엽전 100) |

설화 출정의 기록 반영 원칙: 처치 수·요괴 도감·진화·보스 퇴치(2026-10-20 결정) 같은 누적 기록은 본편처럼 쌓인다. 수련 도장 영구 강화는 설화 출정에도 적용한다(2026-10-20 결정). **막 도달·평정·액운·끝없는 밤 기록은 쌓지 않는다**(설화의 「3막」이 본편 「제3막 도달」 과업을 채우면 안 됨). 엽전은 본편과 같은 계산(막이 셋뿐이라 자연히 적음).

## 5. 오류·예외 처리

- 설화 출정 중 쓰러지면 실패 결과 화면. 조각·열림·빛깔은 그대로.
- 설화 출정 중 「그만두기」는 실패와 같다(기록 없음).
- 흔적은 퇴마 원정·설화 출정·끝없는 밤 두 바퀴째 이후에는 나오지 않는다.
- 흔적이 장애물 속에 생기지 않게 괴이와 같은 자리 고르기(`pushOut`)를 쓴다.
- 이야기 장면 창이 떠 있는 동안 레벨업 등 보상 창은 대기열에서 기다린다(기존 `G.queue` 규칙).
- 옛 저장(`saveVer` 12)으로 시작해도 오류 없이 빈 값으로 시작한다.

## 6. 글 (초안 · 구현 때 문장 다듬기)

### 6-1. 본편 결말 (3부 확정)

**공통 4장**
1. 근정전 앞뜰에서 그슨대가 무너지자, 그 속에서 수많은 그림자가 흩어져 나왔다. 도깨비 웃음소리, 여우 울음, 쇠를 씹는 소리. 모두 어디선가 들어 본 이야기의 소리였다.
2. 할머니 무릎에서 듣던 이야기, 장터 이야기꾼의 입담, 굿판의 무가. 더는 아무도 들려주지 않게 된 이야기들이 갈 곳을 잃고 밤마다 쌓였다. 그 밤이 그슨대였다.
3. 퇴마록이 저절로 펼쳐졌다. 지난밤 물리친 요괴의 이름이 한 줄씩 적혀 있었다. 이름이 적힌 그림자는 더는 사람을 덮치지 않고, 책장 속으로 돌아가 조용히 누웠다.
4. 동이 텄다. 저잣거리에 첫 장이 서고, 주막 굴뚝에서 국밥 김이 올랐다. 누군가 아이를 무릎에 앉히고 입을 열었다. "옛날 옛적, 요괴가 들끓던 조선 팔도에……"

**맺음말**
- 선비: 붓을 꺾으려다 그만두었다. 마지막 장을 덮으며, 이야기를 적는 일이 퇴마의 끝이 아니라 시작이라는 것을 알았다. 그는 서당을 열고, 아이들에게 글보다 옛이야기를 먼저 가르쳤다.
- 의원: 역병이 물러간 마을에서 그는 다시 침을 들었다. 사람을 고치는 일과 이야기를 지키는 일은 닮아 있었다. 둘 다 잊히면 금이 간다.
- 무당: 새벽 굿판에서 그녀는 넋들을 위해 마지막 길닦음을 했다. 흰 무명천 위로 이야기들이 줄지어 건너갔다. 이번에는 아무도 뒤를 돌아보지 않았다.
- 장수: 그는 투구를 벗어 성문 위에 걸었다. 지킬 것은 성이 아니라, 저녁마다 문간에 앉아 이야기를 나누는 사람들이었다. 그는 변방 대신 마을 어귀 장승 곁을 지키기로 했다.
- 기생: 그녀는 잊힌 이야기들로 새 노래를 지었다. 노래가 끝날 때마다 객석 어딘가에서 그림자 하나가 고개를 숙였다가, 웃으며 사라졌다.
- 상인: 장부를 덮으며 외상값 한 줄을 지웠다. 「이야기로 갚음」이라고 적고서. 그날부터 그의 보부상단은 장터마다 물건과 함께 옛이야기를 실어 날랐다.

### 6-2. 전우치전 (초안)

- 조각 1: 송도에 사는 전우치는 어느 날 여우가 입에 문 구슬을 삼키고, 여우에게서 하늘의 글(천서)을 빼앗았다. 그날부터 그의 붓끝에서 구름이 일었다.
- 조각 2: 굶주린 백성을 보다 못한 전우치는 하늘 선관으로 꾸미고 임금 앞에 섰다. 옥황상제의 명이라며 황금 들보를 받아 내, 그것을 팔아 산 곡식을 집집마다 나누었다.
- 조각 3: 탐관오리를 골리고 억울한 이를 돕던 전우치는 끝내 역적이라는 누명을 썼다. 쫓기는 몸이 된 그는, 도술을 거두지 않고 더 깊은 밤으로 숨어들었다.
- 1막 앞: 송도 장터에 흰 여우가 나타났다. 전우치에게 빼앗긴 천서를 되찾으러 온 것이다. 전우치가 웃으며 부채를 펼쳤다. "선비 양반, 같이 가세."
- 2막 앞: 여우의 원한에 도깨비들이 들러붙어 곡식 창고를 노린다. 곡식 섬을 모아 굶는 집에 나누어야 한다.
- 3막 앞: 도술이 지나치면 도술이 사람을 부린다. 전우치의 그림자들이 저 혼자 걸어 나와 마을을 어지럽힌다.
- 결말: 분신들이 흩어지자 전우치는 한참 말이 없었다. 이튿날, 그는 화담 선생을 따라 산으로 들어가 도를 닦기로 했다고 한다. 떠나는 길에 그는 선비에게 쪽빛 도포 한 벌을 건넸다. "글로 싸우는 자에게는 이 빛이 어울리네."
- 출처: 한국민족문화대백과사전 「전우치전」. 게임 속 장면과 싸움은 원전을 바탕으로 새로 지었다.

### 6-3. 지하국대적 (초안)

- 조각 1: 어느 마을의 딸이 하룻밤 새 사라졌다. 땅속 괴물이 데려갔다는 소문에, 부모는 딸을 찾아오는 이에게 재산과 사위 자리를 걸었다.
- 조각 2: 용사는 산속에서 땅 밑으로 난 좁은 문을 찾았다. 밧줄을 타고 내려가던 부하들은 하나둘 겁을 먹고 올라가 버렸고, 용사만 홀로 어둠 속에 내렸다.
- 조각 3: 지하국의 우물가에서 잡혀 온 여인이 용사에게 몰래 물 한 바가지를 건넸다. 「힘내는 물」이었다. 그것을 마시자 큰 바위도 가볍게 들렸다.
- 1막 앞: 굴은 깊고 어둡다. 등불 하나에 의지해 내려간다.
- 2막 앞: 대적의 집 앞 우물. 물 곁을 지키면 힘이 솟는다.
- 3막 앞: 머리 위에서 밧줄이 툭 끊어졌다. 이제 돌아갈 길은 대적을 쓰러뜨리는 것뿐이다.
- 결말: 대적이 쓰러지고 사람들을 밧줄로 올려 보냈지만, 위에 남은 부하들은 밧줄을 거두고 달아났다. 용사가 지하에 홀로 남아 있을 때, 산신의 목소리가 들렸다. 땅 위로 돌아온 용사는 부하들을 벌하고, 마을 사람들이 지어 준 청록 철릭을 입었다.
- 출처: 한국민족문화대백과사전 「지하국대적퇴치설화」. 게임 속 장면과 싸움은 원전을 바탕으로 새로 지었다.

### 6-4. 바리공주 (초안)

- 조각 1: 딸만 일곱을 둔 임금은 막내를 옥함에 담아 버렸다. 버려진 공주는 짐승들과 신령의 손에 자라, 바리공주라 불렸다.
- 조각 2: 세월이 흘러 임금 부부가 깊은 병에 들었다. 저승 너머의 약수만이 살릴 수 있다는데, 여섯 언니도 신하들도 모두 고개를 저었다.
- 조각 3: 바리공주는 "낳아 주신 은혜만으로도 가겠다"며 홀로 길을 나섰다. 저승 가는 길은 멀고, 꽃밭 너머에는 약수를 지키는 이가 기다리고 있었다.
- 1막 앞: 나라에 역병이 돈다. 역병의 신을 물리쳐야 길을 떠날 수 있다.
- 2막 앞: 약수를 지키는 이가 말했다. "물을 긷고 불을 때고 나무를 하라. 그래야 약수를 주겠다."
- 3막 앞: 서천꽃밭. 숨을 살리는 꽃, 뼈를 살리는 꽃, 살을 살리는 꽃을 찾아야 한다.
- 결말: 약수와 꽃을 들고 돌아왔을 때 부모는 이미 숨을 거둔 뒤였다. 바리공주가 꽃을 놓고 약수를 흘려 넣자 두 사람이 눈을 떴다. 그 뒤 바리공주는 저승 가는 넋을 이끄는 신이 되었다고 한다. 무당은 굿판에서 그 이야기를 노래했고, 흰 무명옷을 지어 입었다.
- 출처: 한국민족문화대백과사전·한국민속신앙사전 「바리공주」(디지털 인문학 위키 「바리데기」 인용). 게임 속 장면과 싸움은 원전을 바탕으로 새로 지었다.

### 6-5. 고증 원칙

- 원전 대목과 게임 규칙(창작)을 구분해 적는다(3-2 표의 「근거」 열).
- 실존 인물(서경덕)은 글로만, 존중하는 모습으로 나온다. 사람(부하)과는 싸우지 않는다.
- 설화록 각 편 끝에 출처와 「게임 속 장면과 싸움은 새로 지었다」를 적는다.
- 판본마다 다른 세부(예: 지하국대적의 생김새·퇴치법)는 확인된 대목만 쓴다. 「머리를 베면 다시 붙는다」는 출처 미확인이라 쓰지 않는다.

## 7. 새로 그릴 것 (코드 도트)

흔적 3종(족자·굴 입구·꽃), 곡식 섬, 우물, 꽃 3송이(숨살이·뼈살이·살살이), 설화록·설화 출정 아이콘, 옷 빛깔 3종(색만). 전우치 분신 보스는 기존 전우치 도트.

## 8. 성공의 증거 (시험과 지표)

**단위 시험** (`tests/unit/`)
- `tale_save`: 옛 저장(saveVer 12) → 빈 `meta.tale`·`meta.ending`, saveVer 13, 다른 값 그대로. 엉뚱한 빛깔 id는 null.
- `tale_trace`: 본편에서 흔적 막이고 조각 < 3이면 흔적 예약, 조각 3이면 예약 안 함, 퇴마 원정·설화 출정에서는 예약 안 함. 조사하면 조각 +1, 3이 되면 열림.
- `tale_run`: `taleStart` 뒤 퇴마사·갈래·전직·레벨·무기가 표와 같다. 보스를 쓰러뜨리면 막 사이 장면 → 다음 막(주막·갈림길 없음). 3막 뒤 완주 기록·빛깔 열림. 실패면 기록 없음.
- `tale_rules`: 규칙 9개마다 보스 등장 조건과 효과(예: `well` 최대 +60%, `noHeal` 떡 0개, `plague` 체력 1에서 멈춤).
- `tale_stats`: 설화 출정이 막 도달·평정·액운 기록과 「제3막 도달」 과업을 채우지 않는다.
- `ending`: 본편 제10막 평정 → 공통 장면(처음만) → 맺음말(퇴마사별 처음만) → 끝없는 밤 창. 퇴마 원정·설화 출정에서는 안 나옴.
- `skin`: 빛깔을 고르면 1~5차 모든 차림의 옷 색이 바뀐다.

**브라우저 시험** (`tests/browser/`)
- 흔적 화살표·조사·장면 창, 설화 목록(잠김/열림/완주), 한 판 끝까지, 결말 장면, 설화록 탭을 PC·휴대폰 크기로 열어 넘침·오류 없음. 장면 창 「다음」이 터치·클릭·키로 한 번씩만 넘어감.

**자동 플레이 지표** (설화마다 12판, 보통 수준 봇)
- 한 판 6~8분, 이야기 보스 20~60초, 완주율 60~80%. 표본이 적어 흔들림이 크면 함께 적는다.

**회귀**: 기존 단위 시험 전부, 전직·펫 창 60개 순회, 재현 봇(전직·펫)이 그대로 통과.

## 9. 이번에 하지 않을 것

- 구미호·불가사리·금돼지 등 다른 설화(다음 묶음)
- 설화 출정 어려움 단계, 능력치 보상
- 새 요괴 도트, 새 배경
- 결말 장면 애니메이션(그림 한 장 + 글)

2. **설화 출정 열림 알림**: 장면 창 끝 + 과업 알림 자리 두 곳에 띄운다.
