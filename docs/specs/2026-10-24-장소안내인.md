# 성황당·괴이·샛길 안내인과 상징물 · 설계

- 작성: 2026-10-24 · 대상 판: v17.5
- 상태: 사용자 확인(안내인 A, 말 횟수 A, 시안 승인, 포졸 차림은 첨부 사진 바탕으로 수정) · 문서 검토 대기

## 0. 정해진 것 (결정 기록)

| 질문 | 결정 |
|---|---|
| 안내인 | **A**: 성황당 = 당 지기 할머니, 괴이 = 포도청 포졸, 샛길 = 길잡이 도깨비 |
| 말을 얼마나 | **A 중요한 순간만**: 한 장소에서 나타날 때·가까이 왔을 때·머무는 동안·끝났을 때 많아야 네 번(샛길은 「불이 꺼져 간다」 한 번을 더할 수 있음). 화면 밖이면 가장자리 표지 옆에 한 줄 |
| 도깨비 모습 | 뿔·범 가죽 없음. **패랭이 쓴 키 큰 사내**(퇴마사의 1.4배), 푸른 도깨비불 기운, 방망이 |
| 포졸 차림 | 사용자 첨부 사진 바탕: 검은 전립 + 큰 붉은 상모, 흰 저고리 소매, 남색 쾌자, 파란 허리띠와 앞 매듭, 방망이 |
| 바뀌지 않는 것 | 나오는 시점·자리, 머무는 시간, 판정 거리, 보상, 샛길 선택 창 |

## 1. 목적

세 장소가 퇴마사와 비슷한 크기여서 요괴 사이에 묻히고, 괴이는 평범한 장애물과 거의 같아 보이며, 화면 밖 안내는 작은 삼각형 하나뿐이었다(2026-10-24 캡처로 확인). 장소마다 **멀리서도 모양으로 구분되는 상징물**과 **말을 거는 안내인**을 두어, 무엇이 어디에 있고 무엇을 하면 되는지 알게 한다.

## 2. 플레이어가 보는 것

### 2-1. 상징물과 안내인

| | 상징물 | 안내인 자리 | 빛깔 |
|---|---|---|---|
| 성황당 | 서낭나무(높이 약 50, 가지에 오색 천이 흔들림, 줄기에 금줄) · 지금의 돌무더기 · 작은 장승 | 돌무더기 왼쪽 | 금빛 `#e0b048` |
| 괴이 | 이상해진 물건(지금과 같음) 둘레에 말뚝 넷과 금줄(새끼줄에 고추·숯·흰 종이) | 물건 오른쪽 | 보라 `#c080ff` |
| 샛길 | 지금의 문 · 문 오른쪽에 꽂힌 방망이 · 도깨비불 | 문 왼쪽, 푸른 기운 | 청록 `#5af0d0` |

- 안내인은 숨 쉬듯 1픽셀 위아래로 움직이고, 상징물 쪽을 바라본다. 요괴에게 맞지 않고, 길을 막지 않고, 판정이 없다.
- 「캐릭터·요괴 크기」 2배 설정이면 안내인도 사람처럼 커진다(`entK()`). 상징물은 그대로.
- 절약 모드에서는 오색 천 흔들림·도깨비불 깜빡임을 멈춘다(그림은 그대로 보임).

### 2-2. 말풍선

- 안내인 머리 위, 한지 바탕에 장소 빛깔 테두리, 꼬리 하나. 글은 화면 해상도로 선명하게 그린다(피해 숫자와 같은 방식).
- 한 번에 한 장소당 하나, 2.5초 뒤 사라짐. 화면 밖으로 나가지 않게 좌우를 맞추고, 퇴마사 머리 위와 겹치면 위로 비킨다.
- 글자 크기: 화면에서 12~18px(작은 휴대폰 12px, 큰 PC 화면 18px 상한).
- 「내 기술 효과 진하기」와 상관없이 늘 또렷하다(안내이므로).

### 2-3. 말하는 순간 (한 장소에 각 한 번)

| 순간 | 조건 | 화면 밖이면 |
|---|---|---|
| 나타날 때 | 장소가 생긴 순간 | 가장자리 표지 옆에 같은 말을 3초 |
| 가까이 | 퇴마사와 거리 60 안에 처음 들어옴 | — |
| 머무는 동안 | 진행이 필요 시간의 40%를 처음 넘음 | — |
| 끝났을 때 | 성황당 축복·괴이 조사를 마침. 안내인과 상징물이 1.5초 남아 말한 뒤 흐려짐 | — |
| (샛길) 꺼져 갈 때 | 남은 시간 12초 아래로 처음 내려감 | 가장자리 표지 옆에 3초 |

- 샛길에 들어가면 지금의 도깨비 창이 바로 열리므로 「끝났을 때」 말은 없다. 지나치면 지금처럼 「쳇, 겁쟁이 같으니.」 알림.
- 지금의 알림 문구(「어디선가 성황당의 방울 소리가 들린다」 등)는 그대로 둔다.

### 2-4. 문구 (순간마다 무작위 하나)

**당 지기 할머니** (하게체)
- 나타날 때: 「길손, 이리 오시게」 · 「방울 소리 들리는가?」 · 「서낭님이 기다리시네」
- 가까이: 「돌 세 개 얹고 가시게」 · 「서낭님께 빌어 보시게」 · 「어서 오시게, 젊은이」
- 머무는 동안: 「조금만 더 머무르게」 · 「정성이 닿고 있네」 · 「마음을 모으시게」
- 끝났을 때: 「서낭님이 굽어보시네」 · 「복 받아 가시게」 · 「살펴 가시게」

**포도청 포졸** (하오체)
- 나타날 때: 「퇴마사 나리, 여기요!」 · 「괴이한 일이오!」 · 「여보시오, 이리 좀 와 보시오!」
- 가까이: 「저기 {괴이 이름}이 있소!」(예: 「저기 거꾸로 선 것이 있소!」) · 「해괴하오, 살펴 주시오」 · 「아이고, 또 움직였소」
- 머무는 동안: 「곁에서 살펴 주시오」 · 「조금만 더 보시오」 · 「금줄 밖으로 새지 않게 하오」
- 끝났을 때: 「이제 마음이 놓이오」 · 「포도청에 아뢰겠소」 · 「고맙소, 나리」

**길잡이 도깨비** (반말)
- 나타날 때: 「어이, 퇴마사!」 · 「이쪽이야, 이쪽!」 · 「심심한데 놀다 가」
- 가까이: 「씨름 한 판 하고 갈래?」 · 「내 길로 들어올 테냐?」 · 「겁나면 지나가든가」
- 머무는 동안: 「옳지, 들어와」 · 「한 발만 더!」
- 꺼져 갈 때: 「불 꺼진다, 서둘러!」 · 「곧 문 닫는다!」

### 2-5. 가장자리 표지

- 세 장소의 작은 삼각형을 **상징물 아이콘이 든 네모 + 방향 꼬리**로 바꾼다. 아이콘: 성황당 = 오색 천 달린 나무, 괴이 = 금줄, 샛길 = 방망이와 도깨비불. 테두리는 장소 빛깔.
- 크기: 게임 단위 16(휴대폰에서 약 32px). 말이 붙을 때는 표지 안쪽(화면 가운데 쪽)에 어두운 띠와 장소 빛깔 글.
- 보스·설화 흔적·설화 목표의 화살표는 지금 그대로.

## 3. 만드는 방법

### 3-1. 데이터 (표가 내용을 정한다)

```
GUIDE = {
  shrine: { npc:'halmi',    col:'#e0b048', ic:'shrine', at:[-14,6],  face:1,  lines:{appear:[...], near:[...], stay:[...], done:[...]} },
  anom:   { npc:'pojol',    col:'#c080ff', ic:'anom',   at:[30,8],   face:-1, lines:{...} },   // near의 {n}은 괴이 이름
  dk:     { npc:'dokkaebi', col:'#5af0d0', ic:'dk',     at:[-22,4],  face:1,  sc:1.4, lines:{appear, near, stay, hurry} },
}
GNPC = { halmi, pojol, dokkaebi }   // 문자열 격자 + 팔레트 → variants(mk(...))
GICON = { shrine, anom, dk }        // 10×10 격자
```

### 3-2. 흐름

- 세 장소 객체(`G.shrine`·`G.anom`·`G.dk`)에 `said:{}`(이미 한 순간)와 `say:{txt,t}`(지금 말)를 둔다.
- `guideSay(kind, obj, moment)`: 그 순간을 아직 말하지 않았으면 문구 하나를 골라 `obj.say`에 넣고 `said[moment]=true`. 화면 밖이면 `obj.edgeSay`에 넣는다.
- 부르는 곳: `spawnShrine`·`spawnAnom`·`spawnDk`(appear), 각 `upd`의 거리 검사(near), 진행 검사(stay), 샛길 남은 시간(hurry), 완료 직전(done → `G.gfx`에 1.5초 남는 그림자 하나 추가).
- `G.gfx=[{kind,x,y,t,txt,id}]`: 끝난 장소의 상징물·안내인을 흐리게 그리고 말풍선을 띄운 뒤 사라진다. 막이 바뀌면 비운다.
- 그리기: `drawShrine`·`drawAnom`·`drawDk`에 상징물과 안내인을 더한다. 말풍선과 가장자리 표지는 `BUBQ`·`EDGEQ` 대기열에 넣고, 화면 캔버스에 `drawEmblems` 뒤에 그린다(`drawGuideUI`).
- `edgeArrow` 대신 세 장소는 `edgeSign(kind,x,y,txt)`를 쓴다. 화면 안이면 아무것도 그리지 않는 규칙은 같다.

### 3-3. 오류·예외

- 장소가 사라지는 경우(막 넘김, 보스 처치, 샛길 꺼짐): 말풍선·대기열도 함께 사라진다(`G.gfx`는 막이 바뀌면 비움).
- 설화 출정·퇴마 원정: 장소가 나오는 모드에서는 같은 규칙. 나오지 않는 모드에서는 아무것도 하지 않는다.
- 화면 크기가 바뀌어도 말풍선은 다음 장면에서 다시 맞춘다.
- 저장 형식은 바뀌지 않는다.

## 4. 시험 (시험 먼저)

| 시험 | 확인할 것 |
|---|---|
| 단위 `guide_say` | 세 장소마다 나타날 때 말 1번 → 거리 60 안 near 1번 → 진행 40% stay 1번 → 끝 done 1번(샛길은 hurry), 같은 순간은 두 번 말하지 않음, 문구는 그 순간의 목록 안에서만 나옴, 괴이 near의 {n}이 실제 괴이 이름(조사 「이」), 화면 밖이면 표지 쪽으로 감 |
| 단위 `guide_same` | 머무는 시간·판정 거리·보상 흐름이 v17.4와 같음(성황당 → 축복 창, 괴이 → 조사 보상, 샛길 → 도깨비 창), 안내인은 피해를 받지 않음 |
| 단위 `guide_clear` | 막 넘김·보스 처치·샛길 꺼짐에서 `say`·`G.gfx`가 남지 않음 |
| 브라우저 `guide_ui.py` | 휴대폰·PC에서 세 장소 + 안내인 + 말풍선 캡처(직접 확인), 말풍선이 화면 안·퇴마사 머리와 겹치지 않음, 가장자리 표지 셋이 서로 다른 아이콘·빛깔, 페이지 오류 0 |
| 성능 | 세 장소가 모두 떠 있는 장면의 그리기 시간을 v17.4와 비교(늘어나는 폭 0.3ms 안쪽 목표) |
| 회귀 | 단위 시험 전부, `help_imgs`(도움말 장판 그림이 실제 그리기 함수를 씀), `pick_touch`, `tale_flow`, `ent_size` |

## 5. 고증

- 서낭당: 마을 어귀·고갯마루의 돌무더기, 신목, 백지·오색 천, 장승. 지나가는 이가 돌 세 개를 얹었다. — 한국민족문화대백과사전 「서낭당」 https://encykorea.aks.ac.kr/Article/E0027672 (2026-10-24 확인)
- 금줄: 부정을 막으려 길 어귀나 신성한 대상에 치는 왼새끼, 고추·숯·백지 등을 끼움. — 한국민족문화대백과사전 「금줄」 https://encykorea.aks.ac.kr/Article/E0008002 (2026-10-24 확인)
- 도깨비: 씨름을 걸고 장난을 좋아하나 사악하지 않음, 방망이 등 지물. — 정책브리핑 「새로 태어나는 도깨비(2)」 https://www.korea.kr/news/policyNewsView.do?newsId=65085300 (2026-10-24 확인)
- 뿔 달린 도깨비는 일제강점기 교과서의 오니 삽화에서 퍼졌다는 연구, 전해지는 모습은 「장승같이 큰 놈」·「패랭이를 쓴 놈」. — 뉴시스, 김종대 전 중앙대 교수 인터뷰 https://www.newsis.com/view/NISX20260704_0003695674 (2026-10-24 확인)
- 포졸 차림: 사용자가 준 사진(전립·상모·쾌자·허리띠)을 바탕으로 함. 포졸은 민속 소재가 아니라 게임이 만든 역할.

## 6. 이번에 하지 않을 것

- 안내인과 대화 창, 선택지, 호감도
- 말소리(음성)·새 효과음
- 장소가 나오는 횟수·보상 바꾸기
- 설화 흔적·보스 화살표 모양 바꾸기
