# 한국어·간체 중국어 지원 · 설계

- 작성: 2026-10-24 · 대상 판: v18.0(구조), v18.1(간체)
- 상태: 사용자 방향 승인(「진행」) · 문서 검토 대기
- 용어집: `docs/i18n/용어집.md`(핵심 낱말 확정: 기생 乐伎, 백두산 「白头山（长白山）」→白头山, 동해 朝鲜东海)

## 0. 정해진 것 (결정 기록)

| 질문 | 결정 |
|---|---|
| 언어 | **한국어 + 간체 중국어(简体中文)만**. 영어·번체는 하지 않음 |
| 민속 낱말 | **A 뜻과 한자 중심**. 한국에만 있는 것은 처음 나올 때 괄호 풀이. 도깨비 = 鬼怪 |
| 처음 언어 | **A 기기 언어 따르기**: 브라우저 언어가 `zh`로 시작하면 간체, 아니면 한국어. 고른 언어는 저장 |
| 검수 | **C 원어민 검수 없이 Claude 번역만**. 자동 검사와 반복 교정으로 품질을 지킴 |
| 참고 | LinguaGacha 번역 지침의 **방법**만 참고(프로그램은 쓰지 않음: 상업 프로젝트는 사용 전 제작자 허가가 필요하다고 README에 적혀 있음). 출처를 LOG에 남김 |
| 구조 | 파일이 464KB(규칙 기준 400KB 초과) → `src/` 여러 파일 + `build.py`로 한 장 |

## 1. 목적

중국어 사용 플레이어가 게임 전체(시작 화면부터 결말·도감·도움말까지)를 간체로 막힘없이 즐기게 한다. 한국어 화면은 지금과 글자 하나 다르지 않아야 한다.

## 2. 플레이어가 보는 것

- **시작 화면**: 오른쪽 위에 「한국어 | 中文」 단추. 누르면 그 자리에서 바뀐다(게임 중에는 설정에서). 고른 언어는 저장(`meta.set.lang`).
- **처음 열 때**: 저장된 언어가 없으면 기기 언어로(위 0장).
- **설정**: 「언어」 칸.
- **글꼴**: 중국어일 때만 간체 글꼴을 불러옴. 제목·큰 글자는 지금의 명조 느낌에 맞춰 Noto Serif SC, 본문은 Noto Sans SC(Google Fonts가 필요한 글자 조각만 내려받음). 오프라인이면 기기의 중국어 글꼴로 대신.
- **바뀌는 범위**: 화면의 모든 글(HTML), 게임 데이터(무기·보패·요괴·과업·설화·대사·도움말), 캔버스에 그리는 글(말풍선·피해 표시 문구·도움말 그림 속 글), 알림, 오류 기록 화면.
- **바뀌지 않는 것**: 한자 한 글자 표식(鬼·倒 등 146개)은 두 언어 모두 그대로. 숫자·단축키 글자. 저장 내용(언어를 바꿔도 진행은 그대로).
- **하지 않음**: README·LOG·스팀 스토어 문구의 중국어판(요청하면 따로).

## 3. 만드는 방법

### 3-1. 파일 나누기 (v18.0)

```
src/
  shell.html        # HTML 틀과 CSS (<!--JS--> 자리에 스크립트가 들어감)
  js/00_core.js …   # 지금 스크립트를 순서 그대로 영역별로 나눔(데이터 표, 체계, 화면, 그리기 …)
  i18n/ko.js        # 한국어 문구 표(원문)
  i18n/zh.js        # 간체 문구 표 (v18.1)
build.py            # src → index.html 한 장(지금처럼). --check: 만든 파일과 저장소의 index.html이 같은지
```

- 배포물은 지금처럼 `index.html` 한 장. 시험 도구는 계속 `index.html`을 읽는다.
- v18.0 첫 단계는 **글자 하나 바꾸지 않고 나누기만**: 합친 결과가 지금 `index.html`과 같은지 바이트 비교.

### 3-2. 문구 표 (2026-10-24 구현 전 수정: 원문을 열쇠로)

- 처음 안은 문구마다 이름 열쇠를 붙이고 한국어 표(`ko.js`)를 따로 두는 것이었다. 세어 보니 데이터 표 안의 한국어가 1,652개, 코드 속 문구가 935조각이라, **한국어 원문 자체를 열쇠로 쓰는 방식**으로 바꾼다. 한국어 화면은 원문을 그대로 쓰므로 달라질 위험이 없다.
- 사전: `I18N.zh = { "한국어 원문": "中文", … }`(`src/i18n/zh.js`). 같은 한국어가 뜻이 다를 때만 `"막|무대"`처럼 꼬리표를 붙인다.
- **코드 속 문구**: `t('원문', {변수})`. 한국어면 원문에 변수를 끼워 넣고, 간체면 사전의 번역에 끼워 넣는다. 사전에 없으면 한국어로 보이고 오류 기록에 한 번 남는다.
- 끼워 넣기 `{name}`. 한국어 조사는 `{name:을}`·`{name:으로}`·`{name:이}`·`{name:은}`·`{name:과}`처럼 적는다(지금의 `eul()`·`euro()`와 같은 규칙: 마지막 글자가 한글이 아니면 받침 없음으로 봄, 「으로/로」는 ㄹ받침이면 「로」).
- **데이터 표**(무기·보패·요괴·퇴마사·막·과업·설화·식구 등 대문자 이름의 표): 엔진과 표를 고치지 않는다. 언어를 바꾸면 `applyLang()`이 표를 훑어 한글이 든 문자열을 사전으로 바꾸고, 원문은 따로 기억해 한국어로 돌아갈 때 되돌린다.
- HTML의 고정 글: 원문 그대로 두고 `applyLang()`이 글 마디를 사전으로 바꾼다(원문 기억).
- 캔버스 글꼴은 언어별 글꼴 변수를 읽는다.

### 3-3. 글 꺼내기 도구

- `tools/i18n_extract.py`: 스크립트·HTML에서 한글이 든 문자열을 모두 찾아 목록을 만들고, 옮긴 뒤 **남은 한글 문자열**을 센다(주석 제외). v18.0이 끝나면 데이터·문구 표 밖에 남은 한글 화면 문구 0.
- 지금 셈(2026-10-24): 코드 속 한국어 문구 2,548개(끼워 넣는 틀 242개), 화면 틀 한글 약 1,100자, 캔버스 글 13곳.

## 4. 번역 방법 (v18.1)

1. **용어집 확정**(`docs/i18n/용어집.md` → 기계가 읽는 `src/i18n/glossary.json`). 낱말마다 고정 번역과 적용 조건.
2. **말투 지침**: 서술·안내문(간결한 게임 문체) / 할머니(다정한 옛말) / 포졸(공손한 관원) / 도깨비(장난스러운 구어) / 주모·식구들 / 설화(고풍스러운 이야기체) / 결말(문어체). 말투를 그대로 옮기지 않고 그 말투가 맡은 역할(나이·친밀함·익살)을 중국어로 살린다.
3. **영역별 번역**: 데이터 표 → 화면 문구 → 대사·설화·도움말. 같은 영역은 한꺼번에 번역해 문맥을 지킨다.
4. **글 보호**: `{변수}`, `<b>`·`<br>` 같은 꾸밈, 숫자·%·단축키는 번역하지 않음.
5. **번역 투 손보기**: 대명사 남발, 긴 수식어, 「进行了~」식 명사화, 피동 그대로 옮기기, 「因为…所以…」 남발을 검사 목록으로 손봄.
6. **반복 교정**: 서로 떨어진 영역 세 곳 이상에서 표본을 뽑아 교정 → 찾은 실수 유형(「씨앗」)으로 전체를 다시 훑기 → 새 씨앗이 없을 때까지, 최소 3바퀴. 바퀴마다 찾은 것과 고친 수를 LOG에 남김.

## 5. 시험 (시험 먼저)

| 시험 | 확인할 것 |
|---|---|
| `build.py --check` | `src`를 합친 결과 = 저장소 `index.html`(v18.0 나누기 직후에는 v17.5와 바이트까지 같음) |
| 단위 `i18n_keys` | 한국어·간체 표의 열쇠가 같음, 빈 번역 없음, 끼워 넣는 `{변수}`·꾸밈 태그가 원문과 같음, 데이터 표 모든 아이디에 간체가 있음 |
| 단위 `i18n_josa` | `{n:을}`·`{n:으로}`·`{n:이}` 등이 받침에 맞음(지금 `eul`·`euro` 결과와 같음) |
| 단위 `i18n_glossary` | 원문에 용어집 낱말이 있으면 번역에 고정 번역이 있음(적용 조건이 「문맥대로」인 것은 경고만) |
| 단위 `i18n_lang` | 저장 없음 + 기기 `zh-CN` → 간체, `ko-KR`·`en-US` → 한국어, 저장된 언어가 기기보다 우선, 언어를 바꿔도 진행 저장은 그대로 |
| 브라우저 `i18n_ko_same.py` | 한국어로 화면 40여 개를 열어 v17.5와 화면 글이 같음(v18.0 회귀) |
| 브라우저 `i18n_zh_flow.py` | 간체로 화면 40여 개·레벨업·상자·장면·결과·도움말·설정을 휴대폰·PC에서 열어 **한글 0자**(화면 글과 캔버스 `fillText` 모두), 가로 넘침 0, 페이지 오류 0, 캡처 |
| 회귀 | 지금 단위·브라우저 시험 전부(한국어 기준) |

## 6. 판 나누기

- **v18.0**(플레이어에게 바뀌는 것 없음): `src/` 나누기 → 문구·데이터 표로 옮기기(한국어만) → 언어 바꾸기 장치(중국어는 아직 숨김) → 한국어 회귀.
- **v18.1**: 용어집·말투 지침 확정 → 간체 번역 전체 → 글꼴·언어 단추 공개 → 자동 검사·반복 교정 → 간체 화면 순회.

## 7. 오류·예외

- 번역이 빠진 열쇠: 한국어로 보여 주고 오류 기록에 남김(게임은 계속).
- 글꼴을 못 받음(오프라인): 기기 글꼴. 글자가 네모로 깨지면 안 됨 → 간체 화면 시험에서 확인.
- 옛 저장: `meta.set.lang`이 없으면 기기 언어. 저장 판 번호는 그대로(빠진 값만 채움).
- 언어를 게임 중에 바꾸면: 열려 있는 창은 다시 그리고, 이미 뜬 알림은 그대로 사라지게 둔다.
