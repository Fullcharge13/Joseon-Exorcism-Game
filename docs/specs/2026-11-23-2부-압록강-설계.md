> 작성 2026-11-23. 요청 원문:

## 1. 한 줄 소개

제10막에서 그슨대를 물리친 뒤, 의금부의 판의금부사가 급한 전갈을 가져온다. 명과 청이 싸우는 틈을 타 『산해경』의 요괴들이 압록강을 건너 한양까지 내려왔다. 퇴마사는 한양에서 의주로(義州路)를 따라 북으로 올라가며 다섯 막을 치르고, 요괴들을 압록강 밖으로 몰아낸다.

## 2. 이야기 흐름 (추천안)

```
제10막 막 보스 처치
  └ (처음 평정이면) 본편 결말 — 지금 그대로
  └ 판의금부사 전갈 창 (새)
        ├ 「북으로 간다」  → 제11막 (같은 판, 체력·무기 그대로)
        ├ 「새벽을 맞는다」 → 출정 마침 (지금과 같음)
        └ 「끝없는 밤으로」 → 지금의 끝없는 밤 (그대로 둠)
제15막 막 보스 처치 → (처음이면) 2부 결말 → 「끝없는 밤으로」 / 「새벽을 맞는다」
끝없는 밤(2부를 거친 판): 제1막부터 제15막까지 한 바퀴. 이미 북으로 가기로 했으니 바퀴마다 10막 뒤에 다시 묻지 않고 곧장 11막
```

- 정한 것(사용자 답): 같은 판에서 이어 가기 · 15막 뒤에도 끝없는 밤 · 판의금부사는 이름 없는 가상 인물 · 막 장소 초안대로 · 요괴는 원문 확인 뒤 확정 · 배경음 막 곡 5 + 보스 곡 5 · 설화 출정·원정에는 이번에 안 넣음.

- 2부는 **2부를 고른 사람만** 한다. 10막 평정·액운·흉괘 해금처럼 지금 「제10막」에 묶인 보상과 조건은 **바꾸지 않는다**(이미 깬 사람의 기록이 흔들리지 않게).
- 전갈 창은 처음 한 번은 긴 이야기(3~4쪽), 그 뒤로는 짧은 한 쪽과 선택지만.

## 3. 인물: 판의금부사

- 확인한 사실: 의금부의 으뜸 벼슬 가운데 하나로 **종1품 판의금부사(判義禁府事)**. 다른 관서의 관원이 **겸직**했고, 의금부는 국왕 직속으로 국가 변란 같은 중요 범죄를 다룬 곳.
  출처: 한국민족문화대백과사전 「지의금부사」 https://encykorea.aks.ac.kr/Article/E0054332 (2026-11-23 확인)
- **정함: 이름 없는 가상 인물**(「판의금부사 대감」). 실존 인물을 쓰면 그 사람이 한 일과 날짜를 하나하나 출처로 맞춰야 하고, 실존 인물에게 요괴 이야기를 입히게 된다.
- 왜 의금부인가(게임 속 설정): 나라를 흔드는 변란을 다루는 곳이라, 「요괴가 나라를 친다」는 일을 맡기기에 자연스럽다. 이 문장은 **각색**이라고 설계서에 밝힌다.
- 도트: 관복(종1품 붉은 단령 계열) + 사모. 색과 흉배는 출처를 확인한 뒤 정한다.

## 4. 시대 배경을 다루는 원칙

- 명·청 교체기의 전쟁은 **배경 한 줄**로만 쓴다. 명나라 사람, 청나라 사람, 여진 사람, 중국 사람을 요괴나 적으로 그리지 않는다. 적은 『산해경』 속 **신화의 짐승**이고, 「전쟁의 어지러움을 틈타 깨어났다」는 설정이다.
- 실제 전쟁(정묘·병자호란 등)의 날짜·인물은 쓰지 않는다. 쓰게 되면 백과사전 출처를 단다.
- 동북아 역사 논쟁에 엮인 인물(예: 치우)은 넣지 않는다.
- 『산해경』은 오래된 고전이라 내용은 자유롭게 쓸 수 있지만, **현대 작품(게임·애니)의 디자인은 따라 그리지 않는다.** 원문 묘사(머리 수, 다리 수, 색)만 보고 새로 그린다.

- 모자란 자리(잡귀·엘리트·중간 보스 나머지)는 계획 단계에서 같은 방식으로 원문을 확인해 채우고, 모자라면 앞 막 요괴를 겹쳐 쓴다.
- 이미 있는 구미호(제2막)는 다시 쓰지 않는다.

## 7. 게임에서 바뀌는 곳 (조사 결과)

지금 코드는 곳곳에서 「막은 10개」를 전제로 한다. 2부를 넣으려면 이 자리들을 「1부 10막 + 2부 5막」으로 나눠야 한다.

| 자리 | 지금 | 바꿀 것 |
|---|---|---|
| 막 표 `STAGES` | 10줄 | 15줄 + 「1부 끝 = 10」 표시 |
| 10막 뒤 창 `openEndless` | 끝없는 밤 / 새벽 | 판의금부사 전갈 + 「북으로」 추가 |
| 끝없는 밤 | 1막부터 다시 | 10막 뒤·15막 뒤 모두 고를 수 있음. 2부를 거친 판은 바퀴가 1~15막 |
| 갈림길 `openPath` | 마지막 막 앞에선 생략 | 10막·15막 앞 모두 |
| 원정 모드 `rushRound` | `min(9, …)` | 원정은 10막까지 그대로(추천) |
| 엘리트 행동 `ELITE_AI`·`elite2` | 막 10개 | 새 엘리트 10마리 |
| 막 분위기 `STAGE_VFX`, 배경음 | 10막·21곡 | 막 곡 5 + 보스 곡 5 |
| 막걸리 보상 | 5·10막 보스 | 15막도 |
| 결말 | 10막 첫 평정 | 2부 결말(15막 첫 평정) 새로 |
| 과업 `TASKS` | 10막 기준 | 2부 과업 새로(기존 과업은 그대로) |
| 안내서·도움말 | 「막은 모두 10개」 | 문장 고침 |
| 저장 | — | `meta.best.stage`가 15까지, 새 기록 칸은 기본값 줄만 |

## 8. 난이도 (출발점)

- 요괴 체력 공식 `1 + 막 + 0.15·max(0, 막−2)²`을 그대로 이으면 제15막은 제10막의 약 **2배**(20.6 → 41.4). 목표 지표 「다음 막 받는 피해가 앞 막의 2배 이하」를 지키는지 자동 플레이로 잰다.
- 목표: 막 하나 2.5~3분, 막 보스 20~60초, 2부를 고른 판의 50% 이상이 제13막까지(12판 중앙값). 숫자는 1차 구현 뒤 시뮬레이션으로 정한다.
- 6차 전직(Lv 60)을 2부에서 이루게 할지는 레벨 곡선을 재 보고 정한다.

## 10. 시험 (미리 정하는 것)

- 「10막 평정 → 전갈 창 → 북으로 → 제11막 시작」 흐름 시험
- 「새벽을 맞는다」를 고르면 지금과 같은 보상과 기록(회귀 시험)
- 2부 막마다 잡귀·엘리트·중간·막 보스가 모두 나오고 피해를 받는지

- 원정 모드가 여전히 10막에서 끝나는지
- 새 표의 간체 번역이 비지 않는지(`i18n_cover`)
